# 2026-10-19

## 网站设计与功能诊断（iHangzhou）

对现有站点做了完整诊断，并在 Ardot 画布产出「首页改版概念稿」（fileId 738178937948823）。

### 诊断结论（有代码依据）
- 首页 15 个内容区块同时堆叠，首屏认知负荷过高。
- 导航冗余：旅游/美食等目的地有 4~5 个重复入口（快捷入口、大类网格、怎么玩、热点条）。
- 视觉不一致：CSS 中卡片样式有 28 种不同变体；已有 :root 设计变量但未统一贯彻。
- 技术债：app.js 556KB、style.css 115KB/744 条规则；首页内联 HOME_CATS 与 cat-data.js 数据重复；2756 篇文章为手写 HTML。
- 性能：首屏 JS+CSS 体积大，PWA SW 每次加载强制刷新。

### 改版方向（概念稿已落地）
- 首屏收敛为：今日杭州实时卡 + 全部分类(8) + 为你精选(3) + 便民服务(8) + 底部 5 标签。
- 统一卡片系统：白底 + #e3ddd0 描边 + 14/16 圆角 + 统一图标/字号。
- 品牌色沿用：松绿 #1f7a5a / 鎏金 #c8932b / 帛白 #f7f4ec。

### 技术注意
- Ardot batch_edit 的 operations 必须传 JS DSL 字符串（不能包 JSON 数组）；字符串内用单引号。
- layoutSizingVertical 只接受 'FIXED'|'HUG'|'FILL'（不是 hug_contents）。
- 横向/纵向子框架要撑满需显式 width:'fill_container'，否则会被压成窄条、文字竖排。
- 描边颜色对象不要带 a 键。
