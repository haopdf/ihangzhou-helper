运动健身系列-40：运动后吃什么都行？这几类食物千万别碰，吃错白练

📂 13-运动健身系列 📖 杭州故事

"运动后吃什么，比你练什么更重要。"

开天窗

"我跑完就吃，有什么不可以吃的？"

昨天朋友一边吃着火锅一边跟我喝酒，

我问他："你刚才跑了多少？"

"还就5公里"他说

我看看他眼前那桌——

火锅辣锅

烤啤酒

炸鸡腿

甜点多诱惑

这场景真把我吓到——运动后这么吃，等于白练甚至可能造成更大问题。

运动后饮食的重要性

运动后三件大事

要求说明
补水补汗液、保持水合
糖原补充恢复肌肉能量
蛋白质摄入修复与增长肌肉

吃错问题

吃错结果
过多脂肪阻碍糖原恢复、消化不良
过多糖分升高血糖、脂肪堆积
大量酒精运动后加重炎症、脱水
高盐食品水分失衡、憋人

运动后需要吃的

必需营养物质

营养素作用运动后时机
碳水化合物补充糖原，恢复能量30分钟内
优质蛋白修复损伤肌肉纤维30分钟内
微量元素电解质如钾钠持续补水

运动后推荐食物

碳水化合物

食物每100g碳水含量
米饭25-30g
香蕉20g
燕麦片60-66g
全麦面包45-50g
红薯20-24g
土豆17-20g

蛋白质

食物每100g蛋白含量
鸡胸肉（去皮）23g
鸡蛋13g（每颗约6g）
豆腐（普通）8g
三文鱼20-22g
乳清蛋白粉80g（每勺20-25g）

综合优选

组合理由
鸡肉 + 米饭蛋白 + 碳水平衡
鸡蛋 + 面包简单方便组合
奶昔 + 香蕉蛋白 + 碳水 + 电解质
红薯 + 鲜鱼碳水 + 蛋白

运动后绝对避免的食物

避免食物一：高脂肪食物

食物原因
炸鸡块、炸薯条脂肪高，减缓碳水吸收
烤肉、烤香肠高钠、高脂肪影响恢复
油腻的火锅消化慢、体力恢复差

避免食物二：过多精制糖

食物原因
蛋糕、甜点、奶茶血糖波动剧烈
可乐、饮料营养成分单、糖分高
糖果纯糖、易血糖过峰

避免食物三：酒精饮品

饮品原因
啤酒、酒脱水，且抑制肌肉恢复
鸡尾酒糖分高、脂肪高、酒精

避免食物四：高盐食品

食品原因
腌制品钠过高，影响电解质平衡
咸味零食水分失衡，影响循环

避免食物五：含咖啡因过量

食品原因
浓咖啡、能量饮料心率过高，影响恢复

运动后食物选择原则

原则一：快速吸收入不负担消化

选择原因
简单碳水为主快速补充糖原
易消化蛋白不增加胃肠负担

原则二：均衡组合

推荐原因
蛋白 + 碳水能量恢复与肌肉修复兼顾
添加微量元素促进恢复水合和电解质

原则三：适量控制

建议原因
运动后30分钟内先补简单碳水、蛋白快速恢复期

| 1-2小时后进食正常餐 | 不急不要暴饮

根据训练强度不同选择

低至中等强度训练（慢跑/散步）

时机吃什么
30分钟内一根香蕉 + a杯水
1小时内轻蛋白质（鸡蛋/酸奶）+ 一份碳水

高至高强度训练（力量训练/HIIT）

时机吃什么
30分钟内蛋白粉 + 麦片/香蕉麦芬
1小时内正常正餐（蛋白+碳水+蔬菜）

非常高强度训练（马拉松/超长）

时机吃什么
第一阶段（30分钟内）电解质水 + 蛋白粉
第二阶段（1-2小时内）正常正餐，重点在优质蛋白和碳水

饮水原则

运动后补水指南

时间补水量说明
30分钟内300-400ml温水或电解质水
1小时内继续喝300-500ml根据出汗量影响
2小时内按体重失去的1.5倍补水完全恢复到先前状态
注意小口喝、不要急灌避免肠胃负担

电解质补充

情况推荐电解质饮料
超过1小时训练电解质水
大量出汗钠钾补充饮料
高温高湿环境电解质摇水

替代方案

方案A：运动前适量吃

时间内容原因
运动2-3小时前含有碳水+蛋白的正餐饱足但不饱
运动30分钟前轻量水果+一点蛋白预防运动中低血糖

方案B：随身备运动补给

补给使用方式
电解质水运动中 / 运动后
蛋白粉运动后快速补充
能量棒运动前后适当

水分和营养补给表

项目指标
每小时运动失水0.5-1L（根据强度和环境）
需要总补水量体重的1.5%×体重
蛋白质需求（普通运动）每天0.8-1.2g/公斤体重
蛋白质需求（增强训练）每天1.2-1.8g/公斤体重
碳水需求每天4-7g/公斤体重

写在最后

运动后吃什么这件事，

真的比运动本身更重要。

你每天认真的工作锻炼，

但如果没有正确跟进吃……

等于训练后的努力很多被浪费了。

记住几点：

运动后30分钟内补充简单碳水+蛋白

避免太油腻、太甜、太咸

避免酒精

持续补水、补充电解质

吃对了=练对了恢复得出来

运动很重要，但吃同样重要。
