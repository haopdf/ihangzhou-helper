运动健身系列-40：运动后吃什么都行？这几类食物千万别碰，吃错白练

📂 13-运动健身系列 📖 杭州故事

"运动后吃什么，比你练什么更重要。"

开天窗

"我跑完就吃，有什么不可以吃的？"

昨天朋友一边吃着火锅一边跟我喝酒，

我问他："你刚才跑了多少？"

"还就5公里"他说

我看看他眼前那桌——

火锅辣锅

烤啤酒

炸鸡腿

甜点多诱惑

这场景真把我吓到——运动后这么吃，等于白练甚至可能造成更大问题。

运动后饮食的重要性

运动后三件大事

| 要求 | 说明 |

|-----|------|

| 补水 | 补汗液、保持水合 |

| 糖原补充 | 恢复肌肉能量 |

| 蛋白质摄入 | 修复与增长肌肉 |

吃错问题

| 吃错 | 结果 |

|-----|------|

| 过多脂肪 | 阻碍糖原恢复、消化不良 |

| 过多糖分 | 升高血糖、脂肪堆积 |

| 大量酒精 | 运动后加重炎症、脱水 |

| 高盐食品 | 水分失衡、憋人 |

运动后需要吃的

必需营养物质

| 营养素 | 作用 | 运动后时机 |

|-------|------|-----------|

| 碳水化合物 | 补充糖原，恢复能量 | 30分钟内 |

| 优质蛋白 | 修复损伤肌肉纤维 | 30分钟内 |

| 微量元素 | 电解质如钾钠 | 持续补水 |

运动后推荐食物

碳水化合物

| 食物 | 每100g碳水含量 |

|-----|----------------|

| 米饭 | 25-30g |

| 香蕉 | 20g |

| 燕麦片 | 60-66g |

| 全麦面包 | 45-50g |

| 红薯 | 20-24g |

| 土豆 | 17-20g |

蛋白质

| 食物 | 每100g蛋白含量 |

|-----|----------------|

| 鸡胸肉（去皮）| 23g |

| 鸡蛋 | 13g（每颗约6g）|

| 豆腐（普通）| 8g |

| 三文鱼 | 20-22g |

| 乳清蛋白粉 | 80g（每勺20-25g）|

综合优选

| 组合 | 理由 |

|-----|------|

| 鸡肉 + 米饭 | 蛋白 + 碳水平衡 |

| 鸡蛋 + 面包 | 简单方便组合 |

| 奶昔 + 香蕉 | 蛋白 + 碳水 + 电解质 |

| 红薯 + 鲜鱼 | 碳水 + 蛋白 |

运动后绝对避免的食物

避免食物一：高脂肪食物

| 食物 | 原因 |

|-----|------|

| 炸鸡块、炸薯条 | 脂肪高，减缓碳水吸收 |

| 烤肉、烤香肠 | 高钠、高脂肪影响恢复 |

| 油腻的火锅 | 消化慢、体力恢复差 |

避免食物二：过多精制糖

| 食物 | 原因 |

|-----|------|

| 蛋糕、甜点、奶茶 | 血糖波动剧烈 |

| 可乐、饮料 | 营养成分单、糖分高 |

| 糖果 | 纯糖、易血糖过峰 |

避免食物三：酒精饮品

| 饮品 | 原因 |

|-----|------|

| 啤酒、酒 | 脱水，且抑制肌肉恢复 |

| 鸡尾酒 | 糖分高、脂肪高、酒精 |

避免食物四：高盐食品

| 食品 | 原因 |

|-----|------|

| 腌制品 | 钠过高，影响电解质平衡 |

| 咸味零食 | 水分失衡，影响循环 |

避免食物五：含咖啡因过量

| 食品 | 原因 |

|-----|------|

| 浓咖啡、能量饮料 | 心率过高，影响恢复 |

运动后食物选择原则

原则一：快速吸收入不负担消化

| 选择 | 原因 |

|-----|------|

| 简单碳水为主 | 快速补充糖原 |

| 易消化蛋白 | 不增加胃肠负担 |

原则二：均衡组合

| 推荐 | 原因 |

|-----|------|

| 蛋白 + 碳水 | 能量恢复与肌肉修复兼顾 |

| 添加微量元素 | 促进恢复水合和电解质 |

原则三：适量控制

| 建议 | 原因 |

|-----|------|

| 运动后30分钟内先补简单碳水、蛋白 | 快速恢复期 |

| 1-2小时后进食正常餐 | 不急不要暴饮

根据训练强度不同选择

低至中等强度训练（慢跑/散步）

| 时机 | 吃什么 |

|-----|--------|

| 30分钟内 | 一根香蕉 + a杯水 |

| 1小时内 | 轻蛋白质（鸡蛋/酸奶）+ 一份碳水 |

高至高强度训练（力量训练/HIIT）

| 时机 | 吃什么 |

|-----|--------|

| 30分钟内 | 蛋白粉 + 麦片/香蕉麦芬 |

| 1小时内 | 正常正餐（蛋白+碳水+蔬菜） |

非常高强度训练（马拉松/超长）

| 时机 | 吃什么 |

|-----|--------|

| 第一阶段（30分钟内）| 电解质水 + 蛋白粉 |

| 第二阶段（1-2小时内）| 正常正餐，重点在优质蛋白和碳水 |

饮水原则

运动后补水指南

| 时间 | 补水量 | 说明 |

|-----|--------|------|

| 30分钟内 | 300-400ml | 温水或电解质水 |

| 1小时内 | 继续喝300-500ml | 根据出汗量影响 |

| 2小时内 | 按体重失去的1.5倍补水 | 完全恢复到先前状态 |

| 注意 | 小口喝、不要急灌 | 避免肠胃负担 |

电解质补充

| 情况 | 推荐电解质饮料 |

|-----|----------------|

| 超过1小时训练 | 电解质水 |

| 大量出汗 | 钠钾补充饮料 |

| 高温高湿环境 | 电解质摇水 |

替代方案

方案A：运动前适量吃

| 时间 | 内容 | 原因 |

|-----|------|------|

| 运动2-3小时前 | 含有碳水+蛋白的正餐 | 饱足但不饱 |

| 运动30分钟前 | 轻量水果+一点蛋白 | 预防运动中低血糖 |

方案B：随身备运动补给

| 补给 | 使用方式 |

|-----|---------|

| 电解质水 | 运动中 / 运动后 |

| 蛋白粉 | 运动后快速补充 |

| 能量棒 | 运动前后适当 |

水分和营养补给表

| 项目 | 指标 |

|-----|------|

| 每小时运动失水 | 0.5-1L（根据强度和环境）|

| 需要总补水量 | 体重的1.5%×体重 |

| 蛋白质需求（普通运动）| 每天0.8-1.2g/公斤体重 |

| 蛋白质需求（增强训练）| 每天1.2-1.8g/公斤体重 |

| 碳水需求 | 每天4-7g/公斤体重 |

写在最后

运动后吃什么这件事，

真的比运动本身更重要。

你每天认真的工作锻炼，

但如果没有正确跟进吃……

等于训练后的努力很多被浪费了。

记住几点：

运动后30分钟内补充简单碳水+蛋白

避免太油腻、太甜、太咸

避免酒精

持续补水、补充电解质

吃对了=练对了恢复得出来

运动很重要，但吃同样重要。
