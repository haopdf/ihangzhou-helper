办事系列-06：水电燃气线上缴费指南

📂 办事便利系列 📖 杭州故事

前言：足不出户，轻松缴费

以前每月跑营业厅缴费的日子已经一去不复返了。现在无论水电燃气，都能通过手机轻松搞定。

今天这篇文章，为大家详细讲解水电燃气线上缴费的各种方式。

一、水电燃气基础知识

1.1 三大计费方式

类别计费单位计费周期
水费立方米（m³）每月
电费度（kWh）每月
燃气费立方米（m³）每月

1.2 杭州三费价格参考

类别单价（估算）备注
自来水约4元/立方米居民用水
电费峰时0.56元/度，谷时0.33元/度分时电价
燃气约3.2元/立方米居民用气

二、电费线上缴费

2.1 支付宝缴费

操作步骤：

1. 支付宝首页 → "生活"
2. 点击"电费"或搜索"电费"
3. 输入户号（详见电费单）
4. 绑定账户后自动显示待缴金额
5. 选择支付方式 → 输入密码 → 完成

户号查询：

  • 电费单上有户号
  • 电表箱或住户信息卡

2.2 微信缴费

操作步骤：

1. 微信 → "我" → "服务"
2. 进入"生活缴费"
3. 选择"电费"
4. 输入户号并绑定
5. 确认金额后支付

2.3 浙里办缴费

操作步骤：

1. 浙里办APP → "生活服务"
2. 进入"生活缴费"
3. 选择"电费"
4. 输入户号并支付

2.4 电力营业厅APP（网上国网）

  • 下载"网上国网"APP
  • 注册并绑定户号
  • 查询用量、缴费、办理业务

三、水费线上缴费

3.1 支付宝缴费

操作步骤：

1. 支付宝首页 → "生活"
2. 点击"水费"或搜索"水费"
3. 输入户号（在水费单上）
4. 绑定账户后自动显示待缴金额
5. 选择支付方式 → 支付

3.2 微信缴费

操作步骤：

1. 微信 → "服务" → "生活缴费"
2. 选择"水费"，所在城市"杭州"
3. 输入户号并绑定
4. 确认金额后支付

3.3 水务公司公众号

  • 搜索"杭州水务集团"公众号
  • 绑定户号
  • 可查询用水量、发布通知、缴费

四、燃气费线上缴费

4.1 支付宝缴费

操作步骤：

1. 支付宝首页 → "生活"
2. 点击"燃气费"或搜索"燃气费"
3. 输入户号（燃气表编号）
4. 绑定账户后自动显示待缴金额
5. 选择支付方式 → 支付

4.2 微信缴费

操作步骤：

1. 微信 → "服务" → "生活缴费"
2. 选择"燃气"，所在城市"杭州"
3. 输入户号并绑定
4. 确认金额后支付

4.3 燃气公司公众号

  • 关注"杭州燃气"公众号
  • 绑定户号
  • 可查询用气量、发布通知

4.4 燃气充值（部分区域）

  • 下载"杭燃宝"APP（杭州燃气）
  • 线下IC卡充值后自动录入系统

五、绑定账户与自动缴费

5.1 绑定账户

平台方法
支付宝进入缴费页面，户号绑定成功并选择"记住户号"
微信缴费页面已绑定即可保存
浙里办在绑定页面选择保存户号信息

5.2 自动缴费

平台操作
支付宝绑定首页进入"自动缴费"设置
微信生活缴费 → 开启自动缴费
银行银行APP可设置委托代扣

六、用量查询与账单管理

6.1 用量查询

平台方法
支付宝已绑定账户，首页显示本期用量和本期费用
微信生活缴费首页显示用量和费用
浙里办生活缴费 → 查询 → 用量
公众号杭州水务、燃气公众号可查
APP网上国网APP、杭燃宝等

6.2 账单查看

平台方法
支付宝支付账单 → 生活缴费
微信支付账单 → 生活缴费
银行银行APP账单查看
公众号杭州水务、燃气公众号账单

七、注意事项

7.1 缴费提醒

  • 部分地区有欠费通知，短信或微信提醒
  • 设置支付宝/微信自动缴费可避免忘记
  • 银行代扣可做到及时缴费

7.2 欠费处理

情况处理
欠费短信及时使用线上缴费
物业提醒及时缴费或确认缴费状态
停水停电补缴后一般在2小时内恢复

7.3 缴费时间

  • 建议每月初缴费，避免月末高峰
  • 自动缴费可在每月1日设定
  • 年度可一次性缴纳部分

7.4 电子发票

  • 缴费完成后可申请电子发票
  • 支付宝、微信可直接生成电子发票
  • 也可在客服下载或邮寄

八、常见问题解答

Q1：户号怎么去查找？

A：电费单、水费单、燃气账单上都有户号。也可以在表箱上找到。

Q2：有些人说缴费不成功怎么办？

A：先确认户号正确，查看账户余额、网络问题。如有疑问可联系营业厅客服。

Q3：突然停水、停电，查询欠费方式？

A：登录支付宝/微信生活缴费，输入户号查看，或拨打客服询问。

Q4：自动缴费可以取消吗？

A：可以在支付宝/微信中关闭自动缴费，或在银行.app取消委托代扣。

Q5：缴完费没立刻恢复怎么办？

A：联系967077（供水）或电力95598，查询缴纳是否入账，系统响应延迟。
