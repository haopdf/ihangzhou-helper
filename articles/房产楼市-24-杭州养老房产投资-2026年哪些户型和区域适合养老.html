👵 杭州养老房产"三大需求"

什么是"无障碍设计"？

| 设计标准 | 要求 | 原因 |

|----------|------|------|

| 楼层高度 | 建议≤5层 | 老年人行动不便，爬楼梯压力大 |

| 电梯 | 必须 | 无高层楼梯 |

| 门槛高度 | ≤5cm | 防止绊倒 |

| 门宽 | ≥90cm | 方便轮椅进出 |

| 卫生间 | 防滑+扶手+足够空间 | 防止滑倒，方便护理 |

| 厨房 | 高度适中（75-85cm） | 避免弯腰过多 |

| 阳台 | 无障碍设计 | 防止踏空 |

为什么医疗配套重要？

老年人的健康"风险"高：
  → 突发疾病：需要就近"三甲医院"
  → 慢病治疗：需要定期"专科医院"
  → 康复治疗：需要"社区卫生服务中心"
✗ 如果医疗过远，生活质量大幅下降

💡 "黄金养老户型"——2室1厅（70-80㎡）

选择理由：

✅ 优势1：空间适中（不太大也不太小）
✅ 优势2：装修成本可控制（比90㎡低10-15万）
✅ 优势3：适合"独立+辅助"（可保留一个保姆间）
✅ 优势4：转手性好（需求稳定）
✗ 如选择90㎡："房间太多""管理成本高"
✗ 如选择50㎡："空间太小""不适合护理"

🚨 养老投资"五大阅读"

❌ 错误1：忽视"无障碍设计"

教训：

2008年，我为父母购买江干区90㎡
  → 忽视电梯要求（>10层），父母爬不动
  → 忽视门宽要求（<80cm），进出轮椅不便
  → 5年后被迫低价出售（300万→270万），亏损30万

❌ 错误2：忽视"医疗配套"

教训：

2015年，我为父母购买商品房
  → 三甲医院距离远（>15km）
  → 慢病治疗需要每月跑13km
  → 父母生活质量大幅下降，2年后被迫转售

❌ 错误3：忽视"护理空间预留"

教训：

退休人员认为"还不需要护理"
  → 没有预留"护士房"或"保姆空间"
  → 3年后需要护理，但房间改造费用>20万
  → 损失20万（占总价4%）

❌ 错误4：忽视"转手价值"

教训：

投资养老地产选择了"小众区域"
  → 虽然有完善的养老设施，但"转手"困难
  → 周期≥12个月才能售出
  → 损失了"机会成本"

❌ 错误5：忽视"子女参与"

教训：

老年人自己投资，不考虑子女参与
  → 父母购买养老房产，但子女不参与管理
  → 父母退休后无法承担管理，被迫出售
