运动健身系列-37：久坐腰痛？5分钟告别，这个动作医生都在用

📂 13-运动健身系列 📖 杭州故事

"久坐腰痛不是命，是你没有找到正确的方法。"

开天窗

"我坐8个小时，腰就特别疼。"

昨天一个上班服朋友跟我说，

我不假思索问："那你有起来活动吗？"

回答倒是很有趣："没空啊，开空调跑去工作也不行，只能继续忍着。"

很多人都有这个毛病——

工作忙碌、学习忙碌、生活方式紧张，

一天下来坐在电脑前8-10个小时，

从腰酸开始，到后背辣，

后来到脖子疼、肩膀酸、腿也不舒服。

久坐腰痛这事，不是"工作须要罢了可忍"，你需要 proactive来预防。

久坐腰痛的原因

肌肉不平衡

| 紧张 | 太弱 |

|-----|------|

| 髂腰肌紧张 | 腹横肌太弱 |

| 臀大肌过度放松 | 臀部力量弱 |

| 颈肩肌肉紧张 | 背肌无力 |

结果： 骨盆前倾 → 腰椎承受不均压力 → 腰痛

姿态错误

| 错误 | 影响 |

|-----|------|

| 过度前倾 | 前骨盆，腰椎压力增大 |

| 拱背（驼背） | 胸椎压力，胸廓问题 |

| 肩向前内旋 | 肩颈紧张、颈椎压力 |

| 头颈前伸 | 颈椎负担加重 |

缺乏运动

| 缺乏表现 | 结果 |

|---------|------|

| 髂腰肌拉伸不够 | 臀上部"吊"着 |

| 核肌群无力 | 椎间盆支撑差 |

| 臀腿力量弱 | 久坐时臀腿几乎不动，血液循坏不畅 |

解决久坐腰痛的神奇动作

动作一：猫牛式（脊柱放松）

| 步骤 | 说明 |

|-----|------|

| 1 | 四点着地（_begins on hands/膝盖）|

| 2 | 吸气、背部拱成"牛弓"（脊柱向上拱起）|

| 3 | 呼气、凹背下沉（脊柱下垂成"猫形"）|

| 4 | 反复10次，保持缓慢M型 |

作用：

缓解脊柱紧张、协调背部肌肉和核心。

动作二：髂腰肌拉伸

| 步骤 | 说明 |

|-----|------|

| 1 | 左膝跪在地上，右腿向前伸直落在地 |

| 2 | 轻轻推右腿向前，感受左髂腰肌拉感 |

| 3 | 保持20-30秒，换脚重复 |

| 4 | 每脚2-3组 |

作用：

拉伸长期紧绷的髂腰肌，改善前骨盆。

动作三：背桥（核心与臀强化）

| 步骤 | 说明 |

|-----|------|

| 1 | 垫躺着，膝盖弯曲脚掌贴地 |

| 2 | 臀抬起，身体成"拱桥"形直线 |

| 3 | 保持2秒，缓慢放下 |

| 4 | 完成12次 x 3组 |

作用：

加强臀和核心、支撑腰椎。

动作四：坐姿臂过头胸打开

| 步骤 | 说明 |

|-----|------|

| 1 | 坐在椅子边界，背挺直 |

| 2 | 双手抬过头顶、掌心相贴 |

| 3 | 慢慢上半身向前倾，背部放松 |

| 4 | 保持20-30秒，恢复坐姿 |

作用：

打开胸廓和肩膀，放松肩颈。

动作五：站立后浪

| 步骤 | 说明 |

|-----|------|

| 1 | 站立，双脚与肩同宽 |

| 2 | 双手放在墙上，身体前倾 |

| 3 | 缓慢将腿部向前平移，直到感到髋部前侧轻微拉感 |

| 4 | 保持20秒，2-3组 |

作用：

打开髋部前侧（髂腰肌前伸）、缓解腰痛。

5分钟久坐恢复方案

| 时间 | 动作 | 时长 |

|-----|------|------|

| 0-1分钟 | 猫牛式 | 30秒 each |

| 1-1.5分钟 | 髂腰肌拉伸 | 每侧30秒 |

| 1.5-2.5分钟 | 背桥 | 12次 |

| 2.5-3分钟 | 胸打开 | 30秒 |

| 3-3.5分钟 | 墙跨弓 | 每侧20秒 |

| 3.5-5分钟 | 静坐几句休息 | 深呼吸放松 |

久坐后立刻要做的

立刻站起来

| 行动 | 时间 |

|-----|------|

| 站立起来 | 即刻 |

| 走走2-3分钟 | 必须活动 |

| 伸臂伸展 | 1-2次 |

| 颈部轻转 | 左右各5次 |

做轻度活动

| 活动 | 时间 |

|-----|------|

| 慢绕办公室 | 5分钟 |

| 站立伸展 | 1-2分钟 |

| 走楼梯 | 2-3分钟 |

工作中的久坐预防

方法一：定时提醒

| 解决 | 说明 |

|-----|------|

| 使用APP/闹钟提醒 | 每工作45-50分钟起来5分钟 |

| 同事相互提醒 | 互相提醒站起来 |

方法二：桌子微活动

| 可做 | 不影响工作 |

|-----|-----------|

| 颈轻转 | 适当头部活动 |

| 肩绕环 | 活动肩前后 |

| 轻微抬腿 | 坐时交替抬腿 |

| 腹部轻微收缩 | 轻微收缩腹肌 |

方法三：设置的工作姿势

| 正确 | 避免 |

|-----|------|

| 膝90度 | 腿部过紧 |

| 屏幕与视线同高 | 颈过度前伸 |

| 键盘放在合适高度 | 肩膀过度抬伸 |

方法四：用椅子辅助

| 椅子设置 | 效果 |

|---------|------|

| 座垫高度合适 | 大腿与地面平行 |

| 腰托支撑 | 支撑腰椎 |

| 动态调整使椅子 | 可机动改变姿势 |

长期改善久坐的方法

办公环境改造

| 改造 | 说明 |

|-----|------|

| 调整椅子高度 | 膝、臀、腰对齐 |

| 屏幕高度适宜 | 眼与屏幕水平 |

| 角度可调 | 适应不同工作时 |

| 工作台宽度 | 允许站立工作切换 |

运动习惯养成

| 目标 | 行动 |

|-----|------|

| 每周运动3次 | 每次30-40分钟 |

| 核心训练强化 | 腰腹支持力加强 |

| 髂腰肌和专业拉伸 | 缓解长期紧绷 |

日常姿势调整

| 注意 | 说明 |

|-----|------|

| 站立时不过度前倾 | 保持脊椎自然 |

| 坐桌时避免跷二郎腿 | 远离骨盆别扭 |

| 起身前轻柔地缓慢 | 避免突然性拉伤 |

其他缓解腰痛的方式

补充按摩/理疗

| 方法 | 频率 |

|-----|------|

| 专业按摩 | 每周1-2次 |

| 泡沫轴滚动 | 每天10分钟 |

| 针灸/骨疗 | 每周1次（需要专业医师）|

饮食支持

| 营养 | 作用 |

|-----|------|

| 钙、维生素D | 支持骨密度 |

| omega-3 | 减轻炎症 |

| 水分 | 充足水分以养软骨 |

写在最后

久坐腰痛不是生来就有的，

是习惯造成的，是肌肉的不平衡造成的，

是可以预防的。

花5分钟做这几个动作比吃药还好，

猫牛式放松脊柱，

髂腰肌拉伸缓解前骨盆，

背桥强化臀和核心，

胸打开缓解肩颈，

站立弓步打开髋前，

总共5分钟，你觉得能挤出来，试试这周做几次吧。
