让我重新计算

正确的计算：

🎯 小户型投资的"五大判断标准"

✅ 标准1：现金流压力测试

测试公式：

现金压力指数 = 月供 / 月租金
健康范围：1.0-1.5（现金流覆盖或基本覆盖）
压力范围：1.5-2.5（现金流压力中）
危险范围：>2.5（现金流压力大）
案例：LOFT 40㎡
  → 月供：5,500元/月
  → 月租金：4,500元/月
  → 指数：1.22（健康）
结论：✓ 现金流健康

✅ 标准2：投资回报率计算

投资回报率公式：

净投资回报率 = (年租金 + 5年房价增值) / 总投资(首付) ÷ 5年
案例：LOFT 40㎡
  → 年租金：5.4万
  → 5年增值：5.7%×5年=28.5%（约）
  → 5年房价：140万×1.285=180万
  → 增值：40万
总回报（5年）：5.4万×5 + 40万=27万+40万=67万
总投资（首付）：70万
年化回报率：67万/70万 ÷ 5年=19.1%/年
结论：✓ 投资回报率优秀
