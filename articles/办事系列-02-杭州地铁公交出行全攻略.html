办事系列-02：杭州地铁公交出行全攻略

📂 办事便利系列 📖 杭州故事

前言：杭州出行，一张图搞定

杭州的公共交通日益完善，地铁线路不断延伸，公交网络四通八达。对于新杭州人来说，熟悉这套系统，能让城市生活更加便捷。

今天这篇文章，为大家梳理杭州地铁公交出行全攻略。

2.2 常见出行路径

去西湖景区

  • 地铁1号线 → 龙翔桥站下车 → 步行10分钟
  • 地铁1号线 → 定安路站下车 → 步行15分钟

去西溪湿地

  • 地铁1/3号线 → 古荡站或西溪湿地站 → 步行或打车

去滨江

  • 地铁1号线 → 滨江站 或 滨康路站
  • 地铁6号线 → 江晖路站

去萧山国际机场

  • 地铁7号线 → 萧山国际机场站
  • 也可先乘19号线在机场换乘

三、地铁乘车须知

3.1 票价与支付方式

票种价格区间备注
单程票2-14元根据里程计算
储值卡8折优惠地铁公交通用
二维码9折优惠支付宝/微信
月票/年票按月计算适合通勤频繁者

3.2 支付方式

  • 杭州通：地铁公交乘车卡，可在便利店购买
  • 支付宝：搜索"杭州地铁乘车码"扫码乘车
  • 微信：通过微信小程序"腾讯乘车码"
  • 银联云闪付：支持部分银联卡

3.3 乘车注意事项

  • 首班车：约早上6:00（各站略有差别）
  • 末班车：约晚上22:30-23:00（各线路略有差别）
  • 早晚高峰（7:30-9:00、17:00-19:00人流量大，预留充足时间）

五、公交地铁换乘技巧

5.1 换乘枢纽站

站点可换乘地铁/公交区域
武林广场地铁1/3号线 + 公交8路、16路等市中心

5.2 换乘策略

  • 潮汐通勤：早高峰进城方向人多，可选择反向一站换乘
  • 避开换乘拥挤站：选择两站之间的换乘站
  • 预留空余时间：高峰换乘预留10-15分钟

九、常见问题解答

Q1：地铁进站后停留多久算违规？

A：最长停留时间4小时，超时需按最低票价补票。

Q2：公交卡能在其他城市使用吗？

A：杭州通卡片可在部分长三角城市使用，或开通全国互联互通功能。

Q3：坐地铁可以带宠物吗？

A：除导盲犬外，其他宠物禁止进站上车。

Q4：地铁禁带物品有哪些？

A：易燃易爆物品、刀具等危险品禁止进站，详情请看车站公告。

Q5：能在线上查询公交到站时间吗？

A：可以，通过"杭州公交"APP或高德地图查询实时到站。
