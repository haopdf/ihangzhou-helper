运动健身系列-21：下班后带娃狠练1小时，杭州宝妈的真实运动日常

📂 13-运动健身系列 📖 杭州故事

"不要等'有时间'才去运动，要把运动变成'正常生活'。"

开天窗

晚上7点，我刚下班把闺女接回家，她迫不及待想看动画片。

我刚想说："我们吃完饭再去运动吧。"

然后我看了看时钟——

如果7点开始到8点运动完，晚上8:00吃晚饭、8:40洗澡、9:00哄睡、10:00早睡……完美。

但我当时的第一反应是：太麻烦了，懒得动。

闺女却突然过来拉着我的手说："妈，我们可以去跑步吗？"

我愣了一下——她怎么还记得我周末提过的运动？

我说："今天有点累……"

她说："可是昨天我们在朋友圈看到，张阿姨每天带儿去运动啊"

我突然意识到——

如果我能把这件事做起来，娃也会从小受益。

所以我起身了一下说："好，我们走"

晚上7:00到8:00，我们母女俩做了近一个小时的运动——

她跑了又跳、爬东爬西、一身汗

而我的用户APP告诉我，我今天录入了7200步

说说自律：

其实这不是自律，是觉得过日子里把运动当成一件正常事情——像吃饭一样自然。

1小时能做哪些运动？

方案一：楼下公园循环训练（主打低成本）

| 时间段 | 内容 | 说明 |

|-------|------|------|

| 0-10分钟 | 快走热身 | 一起散步慢走 |

| 10-25分钟 | 玩耍式跑步 | 让娃先跑，妈跟跑 |

| 25-40分钟 | 结合操场器材 | 做简单的器械训练 |

| 40-50分钟 | 舒缓拉伸 | 一起拉伸 |

| 50-60分钟 | 玩耍结束 | 吃水、温言回家 |

需要装备：

运动鞋、舒适运动衣、水壶

地点推荐：

楼下社区公园/小区操场

方案二：小区设施区玩+妈旁边拉伸（主打育儿省力）

| 时间段 | 内容 | 说明 |

|-------|------|------|

| 0-10分钟 | 热身 | 跟随娃一起走路 |

| 10-35分钟 | 让娃在游乐场自由玩耍 | 边上跟着做简单拉伸 |

| 35-50分钟 | 妈做核心训练 | 照顾娃时做平板支撑、臀桥 |

| 50-60分钟 | 一起回家 | 慢走聊天 |

适合情形：

娃忙在游乐设施里，妈可以在边上dynamic地训练，不耽误照看

方案三：跟练视频+娃模仿运动（主打互动）

| 时间段 | 内容 | 说明 |

|-------|------|------|

| 0-10分钟 | 热身 | 一起做跟着视频的热身动作 |

| 10-35分钟 | 跟练持续运动 | 妈妈做正式训练，娃跟着模仿 |

| 35-50分钟 | 舒缓练习 | 娃跟着做比强度的动作 |

| 50-60分钟 | 结束+赞扬 | 说娃你今天做得很好 |

平台推荐：

小红书里搜"少儿运动跟练"/"宝妈晚上运动"就有很多内容

杭州宝妈常去的6个晚间运动场所

1️⃣ 社区公园健身区

| 位置 | 各区都有 |

| 适合运动 | 器械训练、散步、跑步 |

| 收费 | 免费 |

| 夜间照明 | 有，安全 |

理由：

离家近的场所、娃玩器械、妈妈可以用周边器械训练、不用走远路

2️⃣ 滨江篮球场（开放场）

| 位置 | 滨江多处 |

| 适合运动 | 篮娃投篮、妈做开合跳、平板支撑 |

| 收费 | 免费 |

| 夜间氛围好 | 环境照明充分 |

理由：

娃喜欢拍篮球/投篮，妈可以在场边训练

3️⃣ 西湖周边步道（静线）

| 位置 | 西湖外环系统 |

| 适合运动 | 慢跑、散步 |

| 收费 | 免费 |

| 夜间人流 | 比白天少但还能见人 |

理由：

离公园远的话，西湖外环环境好、夜景美

4️⃣ 家中跟练（手机app）

| 位置 | 家中 |

| 适合运动 | 与平台跟练 |

| 收费 | 免费-付费课程 |

| 优点 | 不出门、无需装备

理由：

天冷时候在家最暖和，跟着视频练也可以

5️⃣ 小区周边空地（临时场）

| 位置 | 小区附近空地/广场 |

| 适合运动 | 跳绳、打羽毛球、绳技 |

| 收费 | 免费 |

| 优点 | 靠近、空间大

理由：

不需要固定场所，随便找个空地就能玩

6️⃣ 商场内儿童乐园+妈在休息区瑜伽/拉伸

| 位置 | 各大商场 |

| 适合运动 | 娃玩、妈在休息区的瑜伽垫拉伸 |

| 收费 | 娃有费用、妈免费 |

| 优点 | 温暖、配套完善 |

理由：

天冷时商场暖和，娃玩开心的同时妈做一段瑜伽拉伸

如何克服"太累不想动"？

❌ 常见借口 → ✅ 破解方法

| 借口 | 心态转变 |

|-----|---------|

| "今天太累了" | 动起来才会不累，躺一会儿会更累 |

| "时间不够" | 1小时能完成很多，比想象中少 |

| "没有装备" | 地板就能练，简单装备也行 |

| "娃不愿意" | 娃有玩性，你带头他就会跟着 |

| "怕外人看" | 没有人会在意别人，大家都有自己的事 |

💡 小贴士

| 技巧 | 说明 |

|-----|------|

| 预先准备 | 出门前换好运动装，不给自己后悔的机会 |

| 也是社交 | 约好固定时间段，跟家里人一起 |

| 给小奖励 | 运动1小时=回家给娃一个好吃的零食 |

| 视觉记录 | 拍照打卡，看自己一点进步 |

| 降低期待 | 电脑里不用跑快，运动就行 |

晚间运动注意事项

⚠️ 时间安排

| 注意 | 说明 |

|-----|------|

| 不晚于晚上10点结束 | 再晚可能影响睡眠 |

| 运动1小时左右，不超2小时 | 时间太长会让娃疲惫 |

| 晚宴不要太晚 | 20:00-20:30结束 |

⚠️ 安全事项

| 注意 | 说明 |

|-----|------|

| 人行道边防走 | 避开车辆 |

| 看清娃的位置 | 不要走失 |

| 无照明的地方不去 | 夜间安全首选有照明 |

⚠️ 信号识别

| 症状 | 应对 |

|-----|------|

| 肚子不舒服 | 回家休息 |

| 精力下降 | 慢下来走 |

| 身体酸痛 | 稍休息 |

写在最后

我也不是每天都能完美完成一个小时运动。

有时加班到天黑，娃生病，我也懒得出门。

但只要有七成的一天能坚持，我已经很满意了。

带娃运动不是任务，而是一件母亲和孩子能一起开心完成的事——

娃一边跑一边笑，妈妈看到娃的样子，内心也跟着释然。

下一次，你试着一小时运动，试试看母子俩一起出汗的感觉——

很神奇。
