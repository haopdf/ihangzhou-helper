运动健身系列-47：哪些人不适合跑步？自查这5项如果有，别勉强跑

📂 13-运动健身系列 📖 杭州故事

"不是所有人天生就能跑，跑步需要门槛。"

开天窗

"我就想跑多一点，但上次跑步后膝盖疼了一个多星期"

朋友跟我说，

我问他："你当时是什么情况？"

他说："直接开始跑的，配速也不慢，但还是痛了"

后来我才知道他有几个情况不适合跑步——

膝盖有旧伤、体重过大、从来没有训练基础

跑步虽然是最好的运动之一，但不是所有人都能立刻开始跑。

谁不适合跑步？

不适合人群一：膝关节有问题的人

| 情况 | 建议 |

|-----|------| 膝盖严重损伤/术后 | 不要跑步，改低冲击运动 |

| 轻微膝痛 | 咨询医生，必要时调整跑步方式 |

不适合人群二：体重过重的人

| 体重 | 建议 |

|-----|------| BMI 30+ 或体重超额定 | 先走跑或Active listen 运动 |

| 建议 | 减肥到适合体重后才开始正常跑步 |

不适合人群三：有严重哮喘/心脏问题

| 情况 | 建议 |

|-----|------| 未控制哮喘 | 咨询医生，恢复前不跑步 |

| 严重心脏疾病 | 避免高强度运动 |

不适合人群四：孕妇（严重周期）

| 情况 | 建议 |

|-----|------| 剧烈运动 | 孕妇首选温和运动 |

| 建议 | 医生允许前提下才温和跑步 |

不适合人群五：长期不活动者且反应慢

| 情况 | 建议 |

|-----|------| 初始训练不足 | 不直接跑步，先走+低强度训练 |

自查5项

自查一：膝关节健康

| 检查项 | 说明 |

|--------|------| 爬楼梯有疼？ | 疼痛或不舒服 |

| 跑步后膝盖持续疼 | 需要检查医声 |

| 膝盖曾经有习惯 | 不适合直接跑步 |

自查二：体重指数

| 计算 | 说明 |

|-----|------| BMI = 体重 (kg) / 身高^2 | BMI 25以上要求小心 |

| 建议 | BMI 30+不直接跑步 |

自查三：心血管健康

| 检查项 | 说明 |

|--------|------| 心率异常快 | 咨询医生后 |

| 有高血压 | 需要先控好血压 |

| 心脏有症状 | 咨询医生 deciding

自查四：呼吸系统情况

| 检查项 | 说明 |

|--------|------| 有哮喘史 | 运动前咨询医生 |

| 经常咳嗽 | 咨询专家后才跑步 |

自查五：肌肉骨骼基础

| 检查项 | 说明 |

|--------|------| 有慢性劳损 | 也许做康复运动 |

| 长期姿态不对 | 需要先改善再跑步 |

不适合跑步的人怎么办？

替代运动一：快走

| 优点 | 说明 |

|-----|------| 对膝盖冲击小 | 低冲击 |

| 心肺效果良好 | 和跑步效果相似 |

| 适合人群 | 大部分不跑步都适合 |

替代运动二：骑行

| 优点 | 说明 |

|-----|------| 无关节冲击伤害 | 室内外皆可 |

| 适合室外景观 | 愉受风景同时运动 |

| 适合人群 | 无严重骑行限制的人 |

替代运动三：游泳

| 优点 | 说明 |

|-----|------| 无冲击 | 对关节最友好 |

| 全身锻炼 | 每一处肌肉都能训练 |

| 防止症状 | 水温舒适池 |

替代运动四：椭圆机

| 优点 | 说明 |

|-----|------| 模拟跑步且横轴固 | 适合较大体重 |

| 设备固定 | 不受天气、场地影响 |

替代运动五：瑜伽/拉伸

| 优点 | 说明 |

|-----|----|

| 放松肌肉 | 修复不均，改善姿势 |

| 平衡体态 | 适合久坐人群 |

恢复到能跑的路径

第一步：改善基础条件

| 改善点的 | 说明 |

|-----------|------|

| 减轻到适合的体重 | 先用走、饮食 |

| 恢复膝关节力量 | 康复训练 |

| 改善心血管 | 咨询医生逐步运动 |

第二步：从走开始

| 计划 | 说明 |

|-----|------|

| 慢走开始 | 每天慢走30分钟 |

| 逐渐增快走频 | 从15分钟到20-30分钟 |

| 山坡楼梯训练 | 增加心肺锻炼 |

第三步：走跑结合

| 计划 | 说明 |

|-----|------|

| 走2分钟+跑1分钟 | 交替进行 |

| 逐渐加跑步时间 | 走1分钟+跑2分钟 |

| 持续周期 | 持续4-6周 |

第四步：小配速慢跑

| 计划 | 说明 |

|-----|------|

| 目标配速 7:00-8:00/km | 慢慢跑适合入门者 |

| 每周3次 | 逐渐匹配 |

第五步：正常配速跑步 |

| 计划 | 说明 |

|-----|------| 逐渐增加速度和时长

不适合跑步也别放弃运动

| 不适合跑步 | 其实可以 |

|--------|--------| 膝盖不好 | 骑自行车、椭圆机、游泳 |

| 体重太大 | 快走、骑行、游泳 |

| 心肺不允许 | 温和瑜伽、肌体拉伸

| 姿态有问题 | 康复运动再转入常规运动

最后说话：

跑步是最普及、门槛最低的运动之一，

但不是每个人都能立即开始的。

如果你属于上述几种情况之一——

请认真对待身体给出的信号，不要勉强，

选择适合你的运动方式并坚持下去。

跑步不是唯一的运动方式，变好的目标是更好的身心健康。
