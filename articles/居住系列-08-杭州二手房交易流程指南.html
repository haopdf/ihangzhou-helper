居住系列-08：杭州二手房交易流程指南

前言：二手房交易，流程该如何走？

在杭州购买二手房是很多人的选择，但二手房交易涉及的环节和细节较多，从看房、签约到过户、交房，每一步都需要谨慎。哪些材料需要准备？交易有哪些风险？税费怎么算？

今天这篇文章，为大家详细解析杭州二手房交易全流程，帮助新杭州人顺利完成二手房交易。

一、二手房交易概述

1.1 二手房交易特点

| 特点 | 说明 |

|------|------|

| 房源现房 | 可实地查看具体户型和设施 |

| 配套成熟 | 周边小区、商业配套已经发展 |

| 产权清晰 | 需核实产权和抵押情况 |

| 价格可商 | 买卖双方可以协商价格 |

1.2 交易时间安排

| 步骤 | 一般耗时 |

|------|----------|

| 看房 | 1-2周 |

| 谈判签约 | 3-7天 |

| 贷款审批 | 15-30天 |

| 过户登记 | 5-10天 |

| 交房 | 1-2周 |

| 合计 | 约1-2个月 |

二、交易前准备工作

2.1 买方准备工作

| 准备工作 | 具体内容 |

|---------|----------|

| 预算规划 | 明确可支付的总额（首付+税费+中介费） |

| 资格查证 | 确认购房资格（社保、户口等） |

| 收入证明 | 准备收入证明、银行流水 |

| 征信报告 | 查询个人征信，确认贷款条件 |

2.2 卖方准备工作

| 准备工作 | 具体内容 |

|---------|----------|

| 产权核查 | 确认产权清晰，无纠纷 |

| 房产证 | 准备房产证、土地证 |

| 共有人同意 | 如房产共有，需所有共有人同意 |

| 现房信息 | 整理房屋基本情况、装修信息 |

2.3 房源信息核实

| 核实点 | 检查内容 |

|--------|----------|

| 产权归属 | 核对房产证和身份证是否一致 |

| 面积 | 实际测量面积和房产土地证面积是否一致 |

| 抵押情况 | 是否有抵押、贷款未还清 |

| 租赁关系 | 是否有租赁合同、租客知情 |

| 户口迁移 | 户口是否已迁出（买方可要求） |

三、看房与选择

3.1 看房清单

| 检查项目 | 检查要点 |

|---------|----------|

| 建筑结构 | 墙面、地面是否有裂缝、漏水 |

| 建筑年代 | 推测装修状况、居住年数 |

| 采光通风 | 是否阳光充足、空气流通 |

| 水电燃气 | 是否正常、有无管道问题 |

| 家具家电 | 保留还是拆除、是否需另购 |

| 小区环境 | 小区安全、绿化、停车 |

| 周边配套 | 学校、医院、商场等 |

3.2 看房注意事项

| 注意点 | 说明 |

|--------|------|

| 不同时间段看房 | 选择上午、下午、晚上不同时段查看 |

| 带专业人陪同 | 可找鉴定或装修人员陪同看房 |

| 留意暗房 | 检查厨房、阳台、管道是否漏水 |

| 了解维修记录 | 过去是否曾装修、更换设施 |

| 多套对比 | 不要急于下决断，多套房源对比 |

四、谈判签约

4.1 谈判策略

| 策略 | 说明 |

|------|------|

| 了解市场行情 | 看看同期同小区房源价格 |

| 找出问题点 | 以维修问题等理由压价 |

| 强调自身优势 | 买方付款能力强、卖方急卖 |

4.2 合同签订

| 合同条款 | 详细内容 |

|---------|----------|

| 房屋基本信息 | 名称、地址、面积、产权人 |

| 成交价格 | 含义（净成交价还是含税） |

| 付款方式 | 首付款、尾款、按揭贷款 |

| 过户时间 | 预计过户日期 |

| 学籍关联 | 是否包含学籍 |

| 家具家电 | 留存或拆除 |

| 违约责任 | 买卖双方违约责任 |

| 交付方式 | 交房时间、交接手续 |

| 税费分担 | 各自分担的税费 |

4.3 合同注意事项

| 注意点 | 说明 |

|--------|------|

| 双方签字 | 买卖双方手持，各持一份 |

| 佣金说明 | 中介佣金标准和支付时间 |

| 产权转移 | 确认过户后产权转移时间 |

| 法律建议 | 重大交易建议咨询律师 |

五、贷款办理

5.1 贷款流程

| 步骤 | 说明 |

|------|------|

| 贷款申请 | 提交贷款资料给银行 |

| 资料审核 | 银行审核资质、收入、征信 |

| 房屋评估 | 银行安排评估公司评估房屋价值 |

| 贷款批复 | 银行告知同意贷款金额和利率 |

| 签约立约 | 签借款合同、抵押合同等 |

| 抵押登记 | 去房管部门办理抵押 |

| 贷款发放 | 贷款拨入卖方账户 |

5.2 贷款材料

| 材料 | 说明 |

|------|------|

| 身份证及复印件 | 申请人及配偶 |

| 收入证明 | 工资单、银行流水 |

| 征信报告 | 夫妻双方 |

| 购房合同 | 正式购房合同 |

| 首付证明 | 转账记录、收款凭证 |

| 婚姻证明 | 结婚证/离婚证 |

| 房产证 | 复印件 |

5.3 贷款注意事项

| 注意点 | 说明 |

|--------|------|

| 贷款额度 | 可贷额度取决于房价、收入情况 |

| 贷款利率 | 咨询多家银行，选择最优利率 |

| 提前还款 | 了解提前还款条件及违约金 |

| 贷款保险 | 部分银行要求购买贷款保险 |

六、过户登记

6.1 过户材料

| 材料 | 说明 |

|------|------|

| 双方身份证 | 原件和复印件 |

| 房产证 | 买方已结清贷款需提供 |

| 购房合同 | 复印件 |

| 契税完税证明 | 已缴纳契税证明 |

| 银行贷款合同 | 如有贷款 |

| 户口迁移证明 | 如果买卖双方有房产户口 |

6.2 过户流程

1. 缴纳税费 → 契税、个人所得税、增值税（按规定）
2. 资料准备 → 整理所有过户材料
3. 房管预约 → 通过浙江政务服务网或前往房管中心预约
4. 现场过户 → 当日提交资料、办理登记
5. 领取新证 → 过户完成后领取新房产证（5-10天）

6.3 过户注意事项

| 注意点 | 说明 |

|--------|------|

| 确认税费 | 确认契税、个税等已经缴纳 |

| 核对信息 | 核对新房产证上的面积、地址等信息 |

| 领取时间 | 过户后通常5-10天领取新证 |

七、交房验收

7.1 交房前检查

| 检查项目 | 检查内容 |

|---------|----------|

| 水电燃气 | 确认已办理过户 |

| 家具家电 | 确认有/无、有无损坏 |

| 装修状况 | 检查有无未完成装修 |

| 卫生间厨房 | 查看是否有漏水 |

| 留存物品 | 确认卖方是否留有应收物品 |

| 钥匙交接 | 合同约定的全部钥匙、门禁卡 |

7.2 交接手续

| 手续 | 具体内容 |

|------|----------|

| 水电燃气过户 | 双方前往办理过户 |

| 钥匙交接 | 业主钥匙全移交 |

| 家具家电交接 | 清点、签字确认 |

| 物业交接 | 通知物业变更业主信息 |

| 户口迁移 | 确认原有户口迁移（如需） |

7.3 交房清单

| 项目 | 情况记录 |

|------|----------|

| 水电燃气是否缴纳完毕 | □ 是 □ 否 |

| 家具家电留存 | □ 全留 □ 部分留 □ 无 |

| 房屋是否完好无损 | □ 是 □ 否 |

| 卫生间厨房有无漏水 | □ 无 □ 有 |

| 钥匙门禁卡已移交 | □ 是 □ 否 |

| 物业信息已变更 | □ 是 □ 否 |

八、税费详解

8.1 买方税费

| 税费 | 税率 | 说明 |

|------|------|------|

| 契税 | 1%-3% | 90平米以下1%，以上1.5%-3% |

| 中介费 | 1%-3% | 房屋合同的1%-3%（买卖双方共同分担） |

8.2 卖方税费

| 税费 | 税率 | 说明 |

|------|------|------|

| 增值税 | 5.5% | 满五年唯一住房免征 |

| 个人所得税 | 1%-2% | 满五年唯一住房免征 |

| 土地增值税 | 1%-2% | 商业用房可能征收 |

8.3 税费低价条件

| 情况 | 税费优惠 |

|-------|----------|

| 满五年唯一住房 | 增值税、个税免征 |

| 首套房 | 契税优惠（1%） |

| 拆迁安置房 | 可享一定政策支持 |

8.4 税费预算示例

| 项目 | 金额（房屋300万为例） |

|------|----------------------|

| 契税（首套1.5%） | 约4.5万元 |

| 中介费（2%，各分担一半） | 约3万元（买方负担1.5万） |

| 个税（满五年唯一免） | 0元 |

| 增值税（满五年唯一免） | 0元 |

| 买方总税费 | 约6万元 |

九、风险防范

9.1 常见交易风险

| 风险 | 表现形式 | 防范措施 |

|------|----------|----------|

| 产权模糊 | 房子产权不清晰、有纠纷 | 核实房产证、查档案 |

| 虚假房源 | 买到的房子与图片不符 | 实地看房、核实产权 |

| 价格陷阱 | 以恶性低价吸引 | 对比市场行情 |

| 资金风险 | 付款后房东不交房 | 首付前核实身份、资金监管 |

| 合同陷阱 | 合同条款模糊 | 咨询律师，仔细审核条款 |

9.2 资金监管

| 优势 | 说明 |

| 款项保障 | 只有达到约定条件才能付款 |

9.3 合同审查要点

| 面积 | 面积是否清晰明确 |

| 价格 | 是否明确成交价格 |

| 付款方式 | 首付、尾款、贷款 |

| 交房时间 | 约定交房时间 |

| 违约责任 | 对应违约罚则 |

十一、常见问题解答

Q1：二手房可以公积金贷款吗？

A：可以。只要公积金连续缴纳满6个月且征信良好，可以申请公积金贷款或组合贷款。

Q2：满五年唯一住房免哪些税？

A：满五年唯一住房免增值税和个人所得税，但仍需缴纳契税。

Q3：买二手房需要注意什么？

A：

  • 实地看房，核实房屋状况
  • 核实产权和房产真实性
  • 了解社区环境及邻里关系
  • 明确税费分担
  • 签订正规合同

Q4：中介一定要找吗？

A：不强制，但中介能提供房源信息、协助谈判、协助过户等服务，能缩短成交周期。

Q5：交房后发现问题怎么办？

A：

  • 查合同约定维修责任方
  • 协商处理
  • 必要时通过法律途径
