解决方案概述

VMware Horizon Certificate Automation Solution 是一个完整的自动化证书管理解决方案，专为防止VMware Horizon环境中的证书过期问题而设计。

主要功能

  • 自动证书监控：持续监控VMware Horizon服务器的SSL证书状态
  • 多级预警系统：30/15/7天分级预警机制
  • 多通道告警：支持邮件、Webhook、短信等多种告警方式
  • 告警去重：防止告警信息重复发送
  • 高可用设计：支持主备监控和自动故障切换
  • 安全配置：敏感信息加密存储和权限管理
  • 性能优化：资源使用控制和并行处理
  • 集中日志：统一日志收集和管理
  • 可视化仪表板：HTML报表展示系统状态

部署前准备

系统要求

  • Windows Server 2016 或更高版本
  • PowerShell 5.1 或更高版本
  • 网络访问权限到VMware Horizon服务器的443端口
  • 可选：SMTP服务器用于邮件告警
  • 可选：Twilio账户用于短信告警

权限要求

  • 对VMware Horizon服务器的TCP 443端口访问权限
  • 本地系统读写权限（用于日志和配置文件）
  • 可选：Active Directory权限（用于服务账户管理）

网络配置

确保部署服务器可以访问以下资源：

  • VMware Horizon Connection Servers
  • VMware Horizon Security Servers
  • VMware Horizon Load Balancers
  • SMTP服务器（如果使用邮件告警）
  • Webhook端点（如果使用Webhook告警）
  • Twilio API（如果使用短信告警）

安装和配置

1. 文件部署

将所有脚本文件复制到目标目录（例如：C:\CertificateAutomation）

2. 配置文件设置

服务器配置文件 (servers-config.json)

{
  "Servers": [
    {
      "Name": "ConnectionServer01",
      "Host": "connection01.company.com",
      "Port": 443,
      "Type": "ConnectionServer",
      "Enabled": true
    },
    {
      "Name": "SecurityServer01",
      "Host": "security01.company.com",
      "Port": 443,
      "Type": "SecurityServer",
      "Enabled": true
    }
  ]
}

告警配置文件 (alert-config.json)

{
  "Email": {
    "Enabled": true,
    "SmtpServer": "smtp.company.com",
    "SmtpPort": 587,
    "UseSSL": true,
    "Username": "cert-alert@company.com",
    "PasswordCredential": "EmailPassword",
    "FromAddress": "cert-alert@company.com",
    "Recipients": ["admin@company.com", "it-team@company.com"]
  },
  "Webhook": {
    "Enabled": true,
    "Endpoints": [
      {
        "Name": "Slack",
        "Url": "https://hooks.slack.com/services/YOUR/SLACK/WEBHOOK",
        "Method": "POST"
      }
    ]
  },
  "SMS": {
    "Enabled": false,
    "TwilioAccountSid": "YOUR_TWILIO_SID",
    "TwilioAuthTokenCredential": "TwilioToken",
    "FromNumber": "+1234567890",
    "ToNumbers": ["+1987654321"]
  },
  "Escalation": {
    "INFO": ["Log"],
    "WARNING": ["Email"],
    "HIGH": ["Email", "Webhook"],
    "CRITICAL": ["Email", "Webhook", "SMS"]
  }
}

3. 安全配置

使用Secure-Config-Manager.ps1存储敏感信息：

# 存储邮件密码
.\Secure-Config-Manager.ps1 -Action Store -Key "EmailPassword" -Value "your-smtp-password"
# 存储Twilio令牌
.\Secure-Config-Manager.ps1 -Action Store -Key "TwilioToken" -Value "your-twilio-auth-token"

4. 服务账户配置

创建专用服务账户并设置最小权限：

# 创建服务账户
.\Service-Account-Manager.ps1 -Action Create -Username "svc-certmon" -Description "Certificate Monitoring Service Account"
# 设置文件权限
.\Service-Account-Manager.ps1 -Action SetPermissions -Username "svc-certmon" -Path "C:\CertificateAutomation"

核心组件详解

证书监控 (Certificate-Monitor-Improved.ps1)

基本使用

# 监控单个服务器
.\Certificate-Monitor-Improved.ps1 -Server "connection01.company.com" -Port 443
# 使用配置文件监控多个服务器
.\Certificate-Monitor-Improved.ps1 -ConfigFile "servers-config.json"
# 测试模式
.\Certificate-Monitor-Improved.ps1 -TestMode "valid"    # 模拟有效证书
.\Certificate-Monitor-Improved.ps1 -TestMode "expiring" # 模拟即将过期证书
.\Certificate-Monitor-Improved.ps1 -TestMode "expired"  # 模拟已过期证书

参数说明

  • -Server: 要监控的服务器地址
  • -Port: 服务器端口（默认443）
  • -WarningDays: 警告天数（默认30）
  • -ConfigFile: 服务器配置文件路径
  • -TestMode: 测试模式（valid/expiring/expired）
  • -StateFile: 告警状态文件路径

多通道告警 (Multi-Channel-Alert.ps1)

基本使用

# 发送警告级别告警
.\Multi-Channel-Alert.ps1 -AlertLevel "WARNING" -Subject "Certificate Alert" -Message "Certificate expiring soon"
# 指定收件人
.\Multi-Channel-Alert.ps1 -AlertLevel "HIGH" -Subject "Urgent Certificate Alert" -Message "Certificate expires in 15 days" -Recipients "admin@company.com"

告警级别

  • INFO: 信息性消息
  • WARNING: 警告消息（30天前）
  • HIGH: 高优先级（15天前）
  • CRITICAL: 紧急（7天前）

健康检查 (Health-Check.ps1)

基本使用

# 执行完整健康检查
.\Health-Check.ps1
# 检查特定组件
.\Health-Check.ps1 -Component "Network"
.\Health-Check.ps1 -Component "Config"
.\Health-Check.ps1 -Component "Alert"

日志轮转 (Log-Rotation.ps1)

基本使用

# 执行日志轮转
.\Log-Rotation.ps1 -LogDirectory "C:\CertificateAutomation\Logs" -MaxFileSizeMB 10 -RetentionDays 30
# 压缩旧日志
.\Log-Rotation.ps1 -Action Compress -LogDirectory "C:\CertificateAutomation\Logs"

高级功能使用

高可用监控 (HA-Monitor.ps1)

配置主备监控

{
  "Primary": {
    "Server": "monitor01.company.com",
    "Port": 443,
    "Enabled": true
  },
  "Backup": {
    "Server": "monitor02.company.com",
    "Port": 443,
    "Enabled": true
  },
  "HeartbeatInterval": 300,
  "FailoverThreshold": 3
}

启动HA监控

# 启动主监控
.\HA-Monitor.ps1 -Role Primary -ConfigFile "ha-config.json"
# 启动备监控
.\HA-Monitor.ps1 -Role Backup -ConfigFile "ha-config.json"

性能优化 (Performance-Optimizer.ps1)

优化脚本性能

# 优化性能参数
.\Performance-Optimizer.ps1 -Action Optimize -MaxConcurrentJobs 10 -MaxCpuUsage 80 -MaxMemoryUsage 80
# 监控系统性能
.\Performance-Optimizer.ps1 -Action Monitor
# 生成性能报告
.\Performance-Optimizer.ps1 -Action Report

集中日志收集 (Centralized-Log-Collector.ps1)

收集和管理日志

.\Centralized-Log-Collector.ps1 -Action Collect -LogSource All
# 归档旧日志
.\Centralized-Log-Collector.ps1 -Action Archive -RetentionDays 30
# 生成日志报告
.\Centralized-Log-Collector.ps1 -Action Report

仪表板报表 (Dashboard-Reporter.ps1)

生成HTML仪表板

# 生成默认仪表板

.\Dashboard-Reporter.ps1 -Days 30 -ReportPath "C:\Reports\certificate-dashboard-30days.html"

日常运维操作

1. 计划任务配置

创建Windows计划任务以定期执行监控：

# 创建计划任务（每日执行）
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-ExecutionPolicy Bypass -File C:\CertificateAutomation\Certificate-Monitor-Improved.ps1 -ConfigFile C:\CertificateAutomation\servers-config.json"
$trigger = New-ScheduledTaskTrigger -Daily -At "08:00AM"
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -TaskName "VMware Horizon Certificate Monitor" -Action $action -Trigger $trigger -Settings $settings -Description "Monitor VMware Horizon SSL certificates"

2. 日志管理

定期执行日志轮转和清理：

# 每周日志轮转
.\Log-Rotation.ps1 -LogDirectory "C:\CertificateAutomation\Logs" -MaxFileSizeMB 10 -RetentionDays 90
# 每月归档旧日志
.\Centralized-Log-Collector.ps1 -Action Archive -RetentionDays 30

3. 健康检查

定期执行系统健康检查：

# 每日健康检查
.\Health-Check.ps1 | Out-File -FilePath "C:\CertificateAutomation\Logs\health-check-$(Get-Date -Format 'yyyyMMdd').log"

4. 报表生成

定期生成状态报表：

# 每周生成仪表板报表
.\Dashboard-Reporter.ps1 -Days 7 -ReportPath "C:\Reports\certificate-dashboard-weekly.html"

故障排除

常见问题及解决方案

1. 证书监控失败

问题：无法连接到VMware Horizon服务器

解决方案：

  • 检查网络连通性：Test-NetConnection -ComputerName "server" -Port 443
  • 验证服务器地址和端口配置
  • 检查防火墙设置

2. 告警发送失败

问题：邮件或Webhook告警无法发送

解决方案：

  • 检查告警配置文件中的SMTP设置
  • 验证网络连接到SMTP服务器
  • 检查安全配置中的凭据

3. 脚本执行错误

问题：PowerShell脚本执行出错

解决方案：

  • 检查执行策略：Get-ExecutionPolicy
  • 设置执行策略：Set-ExecutionPolicy RemoteSigned
  • 查看详细错误信息：$Error[0] | Select-Object *

4. 权限问题

问题：脚本无法访问文件或资源

解决方案：

  • 检查服务账户权限
  • 验证文件夹权限设置
  • 使用Service-Account-Manager.ps1重新配置权限
