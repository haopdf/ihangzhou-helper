运动健身系列-44：办公室也要练！不尴尬的8个隐蔽动作，同事都没发现

📂 13-运动健身系列 📖 杭州故事

"上班也能健身？还不让人知道，这才叫高手。"

开天窗

"你想健身，但工作太忙，脑子里就等周末？"

昨天同事跟我说，

他每天8小时坐着，

连运动时间都没有。

我说："其实8小时里，也至少8段各10分钟的空隙时间"

他眼睛一亮："我就有遇到过，比如等外卖、等同事下班、上厕所……"

我笑："的确，这些时间都可以练点隐蔽动作，同事还不知道你在健身"

今天教你8个办公室就能做的隐蔽动作，同事都不会发现你在运动。

为什么办公室也要练？

长久坐的问题

| 部位 | 影响 |

|-----|------

| 颈部 | 疲劳、僵硬、酸痛 |

| 肩部 | 圆肩、肩颈不适 |

| 腰部 | 僵硬、腰酸痛、腰肌劳损 |

| 屁膝 | 膝关节僵硬、血液循环差 |

| 臀腿 | 日久不活动，肌肉萎缩风险 |

办公室小运动的好处

| 好处 | 说明 |

|-----|------|

| 放松肌肉 | 防止肌肉惯性紧张 |

| 促进循环 | 激活血流 |

| 小算运动量 | 不计但累积 |

| 改善姿态 | 办公室坐姿导致的姿态改善 |

办公室隐蔽动作全攻略

动作一：坐姿肩颈绕环（肩颈放松）

| 步骤 | 说明 |

|-----|------|

| 1 | 坐在椅子上，保持背部挺直 |

| 2 | 慢慢转动肩膀前后各10次，轻松节奏 |

| 3 | 颈部缓慢左右绕环10次 |

| 4 | 总体时长约30秒 |

隐蔽性： ⭐⭐⭐⭐⭐ 完全不会被发现

动作二：坐姿膝盖上下（下肢激活）

| 步骤 | 说明 |

|-----|------|

| 1 | 坐在椅子上，两脚轻贴地面 |

| 2 | 慢慢抬起膝盖直到大腿平行地面 |

| 3 | 缓慢放下，每腿重复8-12次 |

| 4 | 注意动作缓慢，不匆忙 |

隐蔽性： ⭐⭐⭐⭐ 轻微动作不易察觉 |

动作三：椅上臀举（增强臀肌）

| 步骤 | 说明 |

|-----|------|

| 1 | 坐在椅子上，脚的后方，手扶桌面 |

| 2 | 缓慢抬起臀部离开椅子 |

| 3 | 保持2-3秒，缓慢放下 |

| 4 | 每腿重复8次 |

隐蔽性： ⭐⭐⭐⭐ 上半身略微可见但不易发现做运动

动作四：楼梯间爬两层（心肺锻炼）

| 步骤 | 说明 |

|-----|------|

| 1 | 去楼梯间，快速爬两层 |

| 2 | 有节奏，保持均匀 |

| 3 | 下两层稍微慢 |

| 4 | 总时间约1分钟 |

隐蔽性： ⭐⭐⭐ 离开办公室，楼梯间少人，但可能遇到同事

动作五：椅边小腿拉伸（放松小腿）

| 步骤 | 说明 |

|-----|------|

| 1 | 站在椅子背后，双手扶椅背 |

| 2 | 一只脚后移伸直，脚跟贴地 |

| 3 | 身体后仰，小腿后侧轻微拉感 |

| 4 | 保持20秒，换脚 |

隐蔽性： ⭐⭐⭐ 姿态看起来像在椅后把握，像说悄悄话

动作六：立姿髋部伸展（髋部放松）

| 步骤 | 说明 |

|-----|------|

| 1 | 找到墙/桌面支撑 |

| 2 | 单脚向前，用脚跟抵住地 |

| 3 | 脚跟不动，前倾身体 |

| 4 | 保持20秒，换脚 |

隐蔽性： ⭐⭐ 姿态看起来像在伸懒腰或走路

动作七：等电梯/等外卖臀侧拉伸

| 步骤 | 说明 |

|-----|------|

| 1 | 站在墙边/门框边 |

| 2 | 手扶墙，外展双腿 |

| 3 | 向一侧倾斜，感受臀内侧拉感 |

| 4 | 保持20秒 per side |

隐蔽性： ⭐⭐⭐ 普通的伸展姿势，容易被当作"休息" |

动作八：椅子中立立点肩绕（肩部微伸展）

| 步骤 | 说明 |

|-----|------|

| 1 | 办公桌前的中立位 |

| 2 | 肩膀向前后绕环10次 |

| 3 | 两手交叉抬过头顶然后放下 |

| 4 | 舒缓肩背紧张 |

隐蔽性： ⭐⭐⭐⭐❓ 你的隔壁可能会观怀疑在做伸展

办公室运动的时机选择

| 时机 | 适合做的动作 |

|-----|-------------|

| 等外卖/等待会议开始 | 动作1、2、3 |

| 如厕/倒水路程 | 动作5（在走廊墙面/门框）|

| 休息5分钟左右 | 动作6、7 |

| 电梯间上去 | 动作4 |

| 工作间歇 | 动作8 |

办公室动作保持隐蔽的技巧

| 技巧 | 说明 |

|-----|------|

| 动作缓慢、有节奏 | 不急速，容易看出来是"伸展"而非"运动" |

| 配合假工作 | 假装在伸懒腰、休息、调整姿势 |

| 眼神自然 | 不要一直盯着镜子旁边的自己 |

| 关闭头耳机 | 听音乐但不让声音漏出来 |

| 配合场景 | 等电梯、等外卖时练，不占用别人的时间 |

办公室动作的注意事项

⚠️ 注意事项

| 注意 | 说明 |

|-----|------|

| 避开在会议室/客户面前做 | 场景不合适 |

| 动作不做太快 | 会被人看出来 |

| 调整呼吸缓慢 | 用鼻子呼吸即可 |

| 不发出巨声 | 不咳嗽、不大声喘 |

| 放到适合的节奏 | 10-20分钟分多次进行，不要旁人侧一直做 |

办公室动作的累积效果

| 效果 | 说明 |

|-----|------|

| 姿态改善 | 长期保持，肩颈放松 |

| 屁膝活动 | 活动关节避免僵硬 |

| 消耗小量热量 | 每天累积200-300卡路 |

| 放松压力 | 减轻久坐带来的小int疲劳 |

办公室运动需要装备吗？

| 装备 | 需要吗？ | 说明 |

|-----|---------|------|

| 专业运动衣 | 不需要 | 日常办公衫就可以 |

| 健身鞋 | 不需要 | 正常鞋子就行 |

| 弹力带 | 可选 | 小巧，可放在抽屉里 |

| 小哑铃 | 可选 | 办公室里隐蔽存放 |

办公室动作不适合的时候

| 时候 | 处理 |

|-----|------|

| 重要会议进行中/会议记录时 | 完全不做 |

| 与客户同处时 | 等际后做，或去别的地方 |

办公室动作的计划示例

8小时理想晨间流程

| 时间 | 做什么 | 时长 |

|------|----------|------|

| 9:00-9:15 | 开始工作前做简单伸展（动作1）| 2分钟 |

| 10:00-10:15 | 等待会议/等工作间隙做肩颈绕环（动作1）| 2分钟 |

| 11:00-11:15 | 去楼梯间爬二层（动作4）| 2分钟 |

| 13:00-13:15 | 等外卖时做坐姿膝盖上下（动作2）| 2分钟 |

| 14:30-14:45 | 椅边凳做臀折叠伸展（动作5）| 2分钟 |

| 16:00-16:15 | 等 Back 队列时做髋部伸展（动作6）| 2分钟 |

| 17:30-17:45 | 离开前补充做肩部伸展（动作8）| 2分钟 |

总计： 约15分钟

写在最后

办公室运动这件事，

**不要以为"要专门空出30分钟才能练"，

其实你能在日常间隙中坐着练习，累积15分钟也不会被察觉。

记住几件事：

动作缓慢别明显 |

选择适合的场景做 |

工作日做至少4次 |

不要事后连身体都没照顾到 |

上8小时坐着，15分钟的小运动起来总比啥都没有的休息好。
