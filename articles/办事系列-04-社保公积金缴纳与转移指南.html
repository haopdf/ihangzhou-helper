办事系列-04：社保公积金缴纳与转移指南

📂 办事便利系列 📖 杭州故事

前言：社保公积金，新杭州人必修课

初到杭州工作，最关心的问题之一就是社保和公积金——怎么缴纳？如何查询？异地转移怎么办理？这些都是关系到切身利益的实用话题。

今天这篇文章，为大家详细介绍社保公积金缴纳与转移指南。

一、社保基础知识

1.1 五险一金是什么？

| 项目 | 内容 | 简单解释 |

|------|------|----------|

| 养老保险 | 保障退休后基本生活 | 工作年限越长，退休金越高 |

| 医疗保险 | 看病报销费用 | 生病时可以报销医疗费 |

| 失业保险 | 失业期间维持生活 | 非本人意愿失业可以领取 |

| 工伤保险 | 工作期间受伤赔偿 | 工伤事故可获医疗和赔偿 |

| 生育保险 | 生育医疗费用报销 | 女职工生育可报销相关费用 |

| 住房公积金 | 储蓄购房及租房 | 可用于购房、租房、还贷 |

1.2 社保公积金缴费比例（杭州市大致标准）

| 项目 | 单位缴费比例 | 个人缴费比例 |

|------|-------------|-------------|

| 养老保险 | 约14% | 约8% |

| 医疗保险 | 约8% | 约2% |

| 失业保险 | 约1% | 约0.5% |

| 工伤保险 | 约0.5% | 0% |

| 生育保险 | 约1% | 0% |

| 住房公积金 | 5%-12% | 5%-12% |

注：实际比例可能根据政策调整

二、社保缴纳

2.1 单位缴纳

| 情况 | 说明 |

|------|------|

| 正式职工 | 单位代缴，个人无需单独办理 |

| 杭州本地单位 | 单位直接到社保局开户 |

| 外地单位驻杭 | 可选择杭州或单位所在地社保 |

2.2 灵活就业人员缴纳

| 缴纳项目 | 比例 | 月缴费（估算） |

|---------|------|---------------|

| 养老 | 20%左右 | 500-1000元 |

| 医疗 | 8%左右 | 200-400元 |

缴纳方式：

  • 浙里办APP线上缴纳
  • 支付宝"社保缴费"功能
  • 各街道政务大厅线下缴纳

2.3 社保查询方式

| 平台 | 功能 |

|------|------|

| 浙里办APP | 查询缴费记录、待遇领取 |

| 支付宝 | 搜索"社保"可查询 |

| 微信 | "城市服务" → "社保查询" |

| 自助终端 | 各政务大厅自助机 |

三、社保转移

3.1 异地社保转移流程

1. 在原参保地办理社保暂停
2. 在原参保地社保局开具《基本养老保险参保缴费凭证》
3. 在杭州新单位入职或个人参保
4. 填写《基本养老保险关系转移接续申请表》
5. 提交材料至杭州社保局
6. 等待转移办理（1-2个月）

3.2 转移所需材料

| 材料 | 说明 |

|------|------|

| 身份证复印件 | 本人身份证 |

| 参保缴费凭证 | 原参保地开具 |

| 申请表 | 杭州社保局办理时填写 |

| 养老手册（如有） | 部分地区需要 |

3.3 网上办理转移

通过"国家社会保险公共服务平台"或"浙里办"APP：

  • 实名认证登录
  • 选择"社保转移"或"养老保险关系转移"
  • 填写转移申请信息
  • 上传材料
  • 提交申请
  • 查询办理进度

3.4 转移常见问题

| 问题 | 回答 |

|------|------|

| 多地参保怎么转移？ | 可选择其中一个合并到杭州 |

| 转移缴费年限怎么算？ | 合并累计计算 |

| 转移影响待遇吗？ | 只要合并后，不影响退休待遇 |

四、公积金缴存与使用

4.1 公积金缴存

| 项目 | 说明 |

|------|------|

| 缴存基数 | 按上年度本人月平均工资 |

| 缴存比例 | 单位和个人各5%-12%，由单位选择 |

| 缴存时间 | 单位入职次月开始缴存 |

| 缴存账户 | 每人一个公积金账户，全国唯一 |

4.2 公积金查询

| 方式 | 说明 |

|------|------|

| 公积金网站 | 浙江省公积金管理中心官网 |

| 浙里办APP | 查询余额、缴存记录 |

| 支付宝 | 搜索"公积金"查询 |

| 客服电话 | 0571-12329公积金热线 |

4.3 公积金使用方式

| 用途 | 使用条件 | 提取额度 |

|------|----------|----------|

| 购买商品房 | 房产证办理后提取 | 账户余额（不超过购房款） |

| 偿还房贷 | 每年一次提取 | 最高不超过年还款额 |

| 租房 | 无房证明、租赁合同 | 每年最高不超过12000元 |

| 离职/退休 | 中断或退休后提取 | 账户全额提取 |

| 大病医疗 | 特定病症 | 按规定比例提取 |

五、公积金转移

5.1 公积金转移流程

1. 在原缴存地办理公积金账户封存
2. 保留公积金账号
3. 杭州入职后，提供原公积金账号
4. 由新单位或本人提出转移申请
5. 填写《住房公积金异地转移接续申请表》
6. 杭州公积金中心与原中心办理转账
7. 办理完成（约1个月内）

5.2 公积金转移所需材料

| 材料 | 说明 |

|------|------|

| 身份证 | 本人身份证复印件 |

| 公积金账号 | 原缴存地的公积金账号 |

| 申请表 | 杭州公积金中心填写 |

| 封存证明 | 如有 |

5.3 异地公积金贷款

| 条件 | 说明 |

|---------|-------|

| 缴存时间 | 连续缴存满6-12个月 |

| 账户余额 | 账户需有一定余额 |

| 贷款额度 | 根据账户余额、房价等计算 |

| 贷款利率 | 低于商业银行利率 |

七、常见问题解答

Q1：公积金取出来会受影响吗？

A：公积金取出来不影响，但会影响贷款额度，建议合理使用。

Q2：社保中断后可以补缴吗？

A：可补缴，但有限制（有时间限制和罚款），建议连续缴纳。

Q3：外地档案转入杭州吗？

A：档案与社保分开，档案可在人才市场或单位管理，社保在社保局。

Q4：公积金不想用了可以取出来吗？

A：只有特定情况下（退休、离职、购房等）才能提取。

Q5：离职后社保怎么办？

A：离职后社保中断，下次入职接续，也可转为灵活就业缴纳。
