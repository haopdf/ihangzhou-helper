4.2 快递柜使用方法

取件

1. 收到取件码短信
2. 前往快递柜所在物品
3. 扫码或输入取件码
4. 取件成功

寄件

1. 打开丰巢/云柜App
2. 选择寄快递
3. 填写收件人信息
4. 放入快递柜
5. 支付
6. 快递员上门取件

4.3 快递柜注意事项

  • 免费存储时间一般为12-24小时，超时收费
  • 贵重物品建议当面验收
  • 取件后记得关闭柜门
  • 注意柜门编号，取错很麻烦

七、寄送物品注意事项

7.1 禁寄物品

| 类别 | 代表物品 |

|------|----------|

| 易燃易爆 | 油漆、酒精、火药 |

| 酒精饮料 | 白酒、啤酒、含酒精化妆品 |

| 化学品 | 农药、有毒化学物品 |

| 违禁品 | 管制刀具、易爆物 |

| 特殊物品 | 活物（特殊渠道除外） |

| 进出口管制文物 | 古董、珍贵文物 |

7.2 贵重物品建议

  • 选择顺丰、京东等安全可靠快递
  • 购买保价（贵重物品务必保价）
  • 打包牢固
  • 收件时当面验收

7.3 异地寄送建议

  • 选择快递时效合适的公司
  • 收件地址详尽准确
  • 收件人电话保持畅通
  • 慎用快递柜，贵重物品选择派送到家

八、常见问题解答

Q1：快递丢了怎么办？

A：联系快递公司客服查询，必要时申请理赔。

Q2：交易商品寄送时如何告知快递？

A：寄送时备注"易碎品"等，贵重物保价。

Q3：快递地址变更怎么办？

A：联系快递客服更新地址，或到快递网点现场申请。

Q4：寄件时用什么包装材料？

A：快递店提供打包材料，特殊商品可自带防震包。

Q5：快递柜超时多久收费？

A：一般免费存储24小时，超时后每2小时收费1-2元。
