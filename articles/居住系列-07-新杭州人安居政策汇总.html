居住系列-07：新杭州人安居政策汇总

前言：新杭州人，政府有支持！

作为新杭州人，在杭州安居乐业是很多人的梦想。为了吸引人才、促进城市发展，杭州出台了一系列安居优惠政策。从人才落户到购房补贴，从公租房到创业支持，如何最大化利用这些政策？

今天这篇文章，为大家汇总新杭州人在杭州居住、就业、创业等方面的相关政策，帮助大家更好地规划在杭州的生活。

一、人才政策概述

1.1 杭州人才分类

杭州将人才分为A、B、C、D、E五类，不同类别享受不同程度的政策支持：

人才类别说明主要领域
A类顶尖人才院士、长江学者等
B类领军人才国家级领军人才、享受国务院津贴专家等
C类高端人才省级领军人才、高级工程师等
D类拔尖人才博士、高级职称人才等
E类基础人才硕士、本科等实用型人才

1.2 人才认定方式

认定渠道说明
在线申请"杭州人才码"APP在线申请
单位推荐按工作单位推荐流程申请
评审认定由人力资源和社会保障局组织认定

二、购房补贴政策

2.1 人才购房补贴标准

人才类别最高补贴金额
A类150万元左右
B类100万元左右
C类80万元左右
D类40万元左右
E类20万元左右

注：具体金额以最新政策为准

2.2 申请购房补贴条件

条件说明
人才认定已通过杭州人才认定
无房记录在杭州无住房记录
住房情况本人及配偶在杭无自有住房
在杭工作与杭州用人单位签订劳动合同
社保缴纳在杭州连续缴纳社保一定期限

2.3 购房补贴申请流程

1. 人才认定 → 提交资料，等待认定结果
2. 购房备案 → 在杭州人才购房系统中备案
3. 提交申请 → 准备材料，提交购房补贴申请
4. 审核公示 → 主管部门审核后公示
5. 补贴发放 | → 监督支付，补贴拨付至个人账户

2.4 申请所需材料

材料说明
身份证申请人身份证及复印件
人才认定文件人才认定证明
购房合同正式购房合同
工资证明收入证明、劳动合同
社保证明社保缴纳证明
银行账号补贴发放账户
无房证明住房情况证明

三、公租房政策

3.1 公租房类型

类型适合人群优惠特点
人才公租房引进人才租金低，政策保障
普通公租房本地及外来务工人员符合收入标准即可申请
廉租房最低收入家庭租金减半，基本保障
集中保租房人才、新就业人员集中居住，配套完善

3.2 公租房申请条件

条件详细说明
年龄年满18周岁
收入家庭收入低于规定标准（因区域不同）
住房在本市无住房或人均住房面积低于标准
社保在本市连续缴纳社保满一定期限（通常6个月以上）
工作列为本市学生或创业人员优先

3.3 公租房租金标准

住房类型租金水平（参考）
人才公租房市场租金的30%-70%
普通公租房市场租金的50%-80%
廉租房市场租金的10%-30%

3.4 公租房申请流程

1. 网上申请 → 通过"浙江政务服务网"或"杭州公租房"APP申请
2. 资格审核 → 相关部门审查资格
3. 摇号分配 | 如房源紧张，会通过摇号分配 |
4. 选房 | 按摇号顺序选房 |
5. 签订合同 | 签署租赁合同
6. 入住 | 支付租金，入住住房

四、落户政策

4.1 落户分类

类型适用人群政策说明
学历落户本科及以上毕业生符合学历的直接落户杭州
技能落户技能证书持有者根据技能等级落户
投资落户投资创业者投资金额达到一定标准
积分落户其他群体通过积分累积落户

4.2 学历落户条件

学历要求
博士年龄放宽至55周岁
硕士年龄放宽至50周岁
本科年龄放宽至45周岁
大专满足技能人才认定

4.3 积分落户

积分项目分值参考
学历本科10分、硕士15分、博士20分
工作年限每年1-2分
社保缴纳每年1-2分
住房自有租赁按面积分
志愿服务每年加1-2分
其他可从政策添加分值

注：每年积分落户分数线不同，详细以当年政策为准

4.4 落户办理流程

1. 准备材料 | → 身份证、户口本、学历证明等
2. 网上申请 | → 在"杭州公安"或"浙里办"申请
3. 开具证件 | → 领取《准迁证》
4. 原户籍迁出 | → 到原户籍地办理迁出
5. 杭州落户 | → 到杭州公安部门落户

十一、常见问题解答

Q1：我是普通本科学历，能享受哪些政策？

A：本科学历可以享受以下政策：

  • 学历落户政策
  • 积分落户政策
  • 公租房申请（符合收入条件）
  • 创业补贴（如创业）
  • 就业服务

Q2：人才认定需要多久？

A：一般审核时间为15-30个工作日。可通过"杭州人才码"APP查看进度。

Q3：公租房租金是怎么计算？

A：公租房租金按市场租金的一定比例计算，具体比例因住房类型不同而不同。

Q4：购房补贴是一次性发放吗？

A：大部分购房补贴是一次性发放，但需要满足条件比如在杭州工作或居住满一定年限。

Q5：如果不符合条件，是否还有其他支持？

A：可能有其他区域、行业、项目的特殊支持政策，如区域优惠、园区补贴等。可根据自身多方咨询了解。
