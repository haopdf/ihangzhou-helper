居家训练的注意事项

⚠️ 场地与安全

| 注意事项 | 说明 |

|---------|------|

| 垫子放在平地 | 避开地毯、硬地不平区域 |

| 旁边留空间 | 做跑步等动作别撞到东西 |

| 家人照顾 | 做动作时别被小孩子干扰 |

| 地板不滑 | 注意垫子下面不滑 |

| 注意噪音 | 做跳跃动作别太吵影响住户 |

⚠️ 饮食配合

| 时段 | 建议 |

|-----|------|

| 训练前30分钟 | 吃点水果或微量元素补给 |

| 训练后 | 喝温水，吃蛋白质补给 |

| 日常保持 | 多喝水不缺水状态 |

居家训练常见误区

误区一：在家没器械所以练不了

❌ 错误想法： 没有器械运动不可能有效

✅ 真相：

  • 很多高级训练完全无需器械
  • 自重训练对新手尤其有效
  • 平时就在家里练的人连临时酒店房间都能训练

误区二：在垫子上趴着也很练

❌ 错误想法： 我在垫子上躺着就算运动了

✅ 真相：

  • 动作需要强度、训练需要坚持
  • 每次训练要有挑战感、不舒适动作也有进步
  • 否则就是动一下=基本不动

误区三：家里没别人看所以练不认真

❌ 错误想法： 没人在旁边，随便练练就算

✅ 真相：

  • 动作标准是基础
  • 不标准的动作没有效果还可能伤自己
  • 可以在镜子前或自拍视频纠正姿势

误区四：在家运动不需要准备

❌ 错误想法： 随时可开始

✅ 真相：

  • 需要合适的服装及鞋子
  • 手机计时记录很重要
  • 水要放在附近备用

居家训练的优势

vs 健身房

| 善处 | 健身房 | 居家 |

|-----|-------|------|

| 成本 | 高 | 低 |

| 时间 | 通勤、排队 | 节省 |

| 取舍 | 需会员卡 | 无需费用 |

| 束缚 | 开放时间限制 | 可随时实操 |

| 器械 | 很多 | 自重/简单道具 |

健身办卡很好，但如果没时间/预算害怕，居家训练一样好。

vs 户外运动

| 善处 | 户外 | 居家 |

|-----|------|------|

| 天气 | 需适合 | 全天候 |

| 时间 | 需路程 | 无需路程 |

| 场地 | 公园、绿道 | 一块垫子就够 |

| 社交 | 可能与人同动 | 独自训练 |

| 风景 | 自然风光 | 可以 听歌/电影 |

居家训练的台词是：一句话又简单，又舒适。
