办事系列-07：浙江政务服务网使用教程

📂 办事便利系列 📖 杭州故事

前言：一个网站，办遍所有政务

浙江政务服务网（浙里办）是浙江省统一的在线政务服务平台，"网上办、掌上办、一网通"。只要在这一个网站或APP上，就能办理大部分政务服务。

今天这篇文章，手把手教大家使用浙江政务服务网。

一、浙江政务服务网概述

1.1 平台组成

| 平台 | 功能 | 使用场景 |

|------|------|----------|

| 浙江政务服务网 | 电脑端网页 | 复杂业务、材料上传 |

| 浙里办APP | 手机端 | 日常查询、简单业务办理 |

| 浙里办小程序 | 微信/支付宝小程序 | 快捷查询、办理 |

| 12345热线 | 电话热线 | 政策咨询、投诉建议 |

1.2 办理服务类型

| 服务类型 | 说明 |

|---------|------|

| 个人服务 | 户籍、社保、医保、公积金、居住证等 |

| 法人服务 | 企业注册、税务申报、资质审批等 |

| 公共服务 | 天气查询、办事指南、便民服务 |

二、账号注册与登录

2.1 网页版注册

1. 打开浙江政务服务网网站（www.zjzwfw.gov.cn）
2. 点击右上角"注册"
3. 选择"个人注册"或"法人注册"
4. 填写手机号、设置密码
5. 验证手机号，完成注册
6. 进行实名认证（上传身份证照片或人脸识别）

2.2 浙里办APP注册

1. 下载"浙里办"APP
2. 打开APP，点击"注册"
3. 填写手机号、设置密码
4. 验证手机号，完成注册
5. 进行人脸识别实名认证
6. 完成注册即可使用全部功能

2.3 登录方式

| 方式 | 说明 |

|------|------|

| 账号密码 | 使用注册的手机号和密码 |

| 手机验证码 | 输入手机号和验证码登录 |

| 人脸识别 | 实名认证后可刷脸登录 |

| 第三方登录 | 支付宝、微信快捷登录 |

三、个人服务办理

3.1 社保服务

办理项目：

  • 社保查询
  • 社保转移申请
  • 社保补缴申请
  • 社保证明下载

操作步骤：

1. 浙里办首页 → "社保"
2. 进入个人社保页面
3. 选择"社保查询"或"社保转移"
4. 按提示填写信息
5. 提交申请或在线查询

3.2 医保服务

办理项目：

  • 医保缴费查询
  • 异地就医备案
  • 医保报销查询
  • 医保电子凭证激活

操作步骤：

1. 浙里办首页 → "医保"
2. 进入医保专区
3. 选择相应服务
4. 填写信息提交
5. 在线查询办理结果

3.3 居住证服务

办理项目：

  • 居住证申请
  • 居住证续签
  • 居住证挂失补领
  • 居住证明下载

操作步骤：

1. 浙里办首页搜索"居住证"
2. 进入居住证办理页面
3. 填写个人基本信息
4. 上传身份证、租房合同等材料
5. 提交申请
6. 等待审核结果
7. 审核通过后到现场核验或邮寄送达

3.4 公积金服务

办理项目：

  • 公积金查询
  • 公积金提取申请
  • 公积金贷款申请
  • 公积金转移申请

操作步骤：

1. 浙里办首页 → "公积金"
2. 进入公积金专区
3. 选择相应服务
4. 填写信息并上传材料
5. 提交申请
6. 查询办理进度

3.5 户籍服务

办理项目：

  • 户籍迁移申请
  • 身份证补办
  • 户口本补办
  • 户籍信息变更

注意：部分户籍业务需到现场办理，线上可提交申请和材料

四、法人服务（企业办理）

4.1 企业注册

流程：

1. 进入"企业开办"服务
2. 填写企业基本信息
3. 上传营业执照等材料
4. 网上预核名
5. 提交申请
6. 审核通过后到现场核验
7. 领取营业执照

4.2 税务服务

办理项目：

  • 税务登记
  • 税务申报
  • 发票申领
  • 税务查询

4.3 许可证办理

类型：

  • 食品经营许可证
  • 卫生许可证
  • 文化经营许可证
  • 消防许可证
  • 其他行业许可证

五、便民服务

5.1 天气查询

  • 浙里办首页 → "天气"
  • 查看杭州及各地天气预报

5.2 办事指南

  • 搜索具体事项（如"生育保险"）
  • 查看办理条件、材料、流程

5.3 投诉建议

  • 浙里办 → "投诉建议"
  • 填写投诉内容并上传证据
  • 提交后可查询处理进度

六、常用功能快捷方式

6.1 搜索功能

  • 在首页搜索栏输入关键词
  • 快速找到相关服务

6.2 收藏功能

  • 常用服务可收藏到"我的收藏"
  • 以后快捷访问

6.3 消息通知

  • 办理进度、系统通知会推送
  • 及时关注有新消息

七、注意事项

7.1 材料准备

  • 提前准备所需材料（身份证、户口本、社保证明等）
  • 材料需清晰扫描或拍照
  • 保持材料真实有效

7.2 办理时限

  • 简单业务：1-3个工作日
  • 复杂业务：7-15个工作日
  • 可在线查看办理进度

7.3 查询办理结果

  • 浙里办"我的办事"→查看进度
  • 办理完成后显示"办结"
  • 生成电子证照或送达实体证照

八、常见问题解答

Q1：忘记密码怎么办？

A：登录页面点击"忘记密码"，通过手机验证码重置。

Q2：线上提交的材料有误怎么办？

A：在提交前可修改，提交后如审核未通过可重新提交。

Q3：办理进度持续显示"审核中"怎么办？

A：等待1-2周，如仍未进展可联系客服或12345政务热线咨询。

Q4：办理失败原因有哪些？

A：材料不符、信息错误、有其他不符合条件情况，需根据反馈修改后重新申请。

Q5：电子证照和纸质证照效力一样吗？

A：电子证照具有同等法律效力，可在政务服务中直接使用。
