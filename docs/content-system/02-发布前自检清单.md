# iHangzhou 发布前自检清单（AI 写完 → 你/AI 逐条勾选）

> 用途：AI 写完正文后，按本清单核对。任一红项不通过，打回重写。
> 这套清单就是把"风格统一 + 选题不跑偏"变成可勾选的硬检查，不靠感觉。

## A. 标题与选题（防跑偏）
- [ ] 标题套用了四种公式之一（数字/反差/痛点/悬念）
- [ ] 标题承诺的卖点，正文已逐条兑现（无空头标题党）
- [ ] 选题是杭州本地内容，符合账号定位
- [ ] 大纲每节都服务于标题，无偏离 >1 个核心点

## B. 结构完整度
- [ ] 开头 100 字内有场景代入（不是"今天给大家介绍…"）
- [ ] 正文 3–5 小节，每节有 emoji+短句小标题
- [ ] 含小贴士模块：地址 / 人均 / 交通 / 开放时间
- [ ] 结尾有总结 + 互动提问（非"关注我"式硬广）
- [ ] 正文 1200–1800 字

## C. 声音一致性（风格统一）
- [ ] 用"你"对话，朋友聊天语气，无官方腔
- [ ] 无禁用词（震惊/速速/绝绝子/家人们/史上最…）
- [ ] emoji ≤ 3 个，不堆砌
- [ ] 每 800 字至少 1 句可截图金句
- [ ] 本地化具体地名，无"某景区/该市"抽象词

## D. 真实性与安全
- [ ] 数据/价格/花期/票价真实可查，文末附来源
- [ ] 未编造、未贬低具体商家
- [ ] 配图合规（官方/自拍/授权），无盗图

## E. 跨 AI 一致性校验（切换模型后必查）
- [ ] 与本账号其他文章语气一致（像同一个"朋友"写的）
- [ ] 未混入其他 AI 的通用模板腔（如"首先…其次…最后…"八股）
- [ ] 主色/封面风格与品牌松绿 #1f7a5a 一致

---

**打回标准**：A 类任一项不通过 → 必须重写；B/C 类累计 ≥3 项不通过 → 打回修改。
