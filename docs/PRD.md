# iHangzhou 杭州生活助手 · 产品需求文档（PRD）

> 版本：v2.0 · 独立版
> 日期：2026-09-07
> 定位：仿杭州本地宝（hz.bendibao.com）移动版的杭州城市生活导航 H5/PWA

---

## 一、产品概述

### 1.1 产品定位
iHangzhou 是一款面向杭州本地居民与新市民的**城市生活导航 H5**，聚合政务办事、交通出行、民生服务、生活消费、文化旅游等高频场景的官方入口，让用户"一站直达官方渠道"。

- **目标用户**：杭州常住居民（25-55岁）、新杭州人（落户/求职/租房群体）、来杭办事/旅游人群
- **核心价值**：**官方、可信、零干扰**——所有外链均指向政府/官方/品牌渠道，不存储用户数据，不做信息流推荐
- **差异化**：本地宝以"资讯+专题"驱动，iHangzhou 以"工具+导航"驱动，更轻、更快、更聚焦

### 1.2 产品形态
| 维度 | 说明 |
|---|---|
| 形态 | 移动端 H5（Mobile First）+ PWA 可安装 |
| 后端 | 纯静态，零后端依赖，可部署 Vercel/Cloudflare Pages/GitHub Pages/OSS |
| 域名 | ihangzhou.net |
| 数据 | 所有服务配置内联在 `data/services.json` 与 `js/app.js` |
| 兼容 | iOS 13+ / Android 8+ / 主流浏览器（Chrome/Safari/Edge/Firefox） |

### 1.3 与本地宝的定位差异
| 维度 | 本地宝 hz.bendibao.com | iHangzhou |
|---|---|---|
| 内容驱动 | 资讯+专题（编辑团队日更） | 工具+导航（聚合官方入口） |
| 商业模式 | 广告+导流分成 | 公益导航，无广告 |
| 信息层级 | 三级以上（首页→专题→文章） | 扁平两级（首页→分类→详情/外链） |
| 用户动线 | 阅读 → 搜索资讯 | 直达 → 官方入口 |
| 离线 | 不支持 | PWA 离线访问核心页 |

3. **电话** 📞 — 常用电话簿
4. **我的** 👤 — 个人/设置/关于

## 三、功能模块详述

### 3.1 首页（Home）

#### 3.1.1 顶部栏
- **城市切换**：左上角"杭州 ▼"，预留多城扩展（默认杭州，未来可扩展宁波/温州）
- **搜索框**：中部，placeholder "搜索服务..."，支持服务名/关键词模糊匹配
- **主题按钮**：右上角 🌙/☀️，切换深色/浅色模式，偏好本地存储

#### 3.1.2 金刚区（8 宫格）
- 布局：4 列 × 2 行，圆角图标 + 文字
- 数据：取自 `DATA.hotServices` 前 8 项
- 交互：点击触发 `action`（内置工具）或 `url`（外链新窗口打开）

#### 3.1.3 资讯 Banner
- 位置：金刚区下方
- 形态：横向轮播，2-3 条
- 内容：政策更新/活动通知/便民提醒
- 交互：点击跳转公众号文章或官方页

#### 3.1.4 频道宫格
- 布局：4 列 × 3 行，共 12 频道
- 每个频道对应一个专题页（未来扩展，v2 先做入口）
- v2 范围：点击频道高亮，暂不跳转专题页

#### 3.1.5 热门搜索
- 位置：频道宫格下方
- 数据：`DATA.hotKeywords`（12 词）
- 形态：标签云，点击即填入搜索框并触发搜索

#### 3.1.6 分类 Tab + 服务网格
- Tab：横向滚动，10 个分类
- 服务网格：2 列卡片，每张卡片显示 icon + name + desc
- 卡片交互：
  - 有 `url`：新窗口打开官方链接
  - 有 `action`：打开模态框执行内置工具
  - 默认：打开模态框显示服务详情

### 3.2 工具页（Tools）

#### 3.2.1 计算器
| 工具 | 输入 | 输出 | 数据源 |
|---|---|---|---|
| 个税计算 | 税前月薪、社保基数 | 应纳税额、税后收入 | 2026 税率表（内联） |
| 房贷计算 | 贷款金额、年限、利率 | 月供、总利息 | LPR + 商贷公式 |
| 社保计算 | 工资基数、类型 | 个人/单位缴费明细 | 杭州社保比例（内联） |
| 公积金贷款 | 贷款额、年限 | 月供、利息 | 公积金利率（内联） |

#### 3.2.2 实时查询
| 工具 | 数据来源 | 更新频率 |
|---|---|---|
| 限行查询 | 本地规则（按日期+尾号） | 每日 |
| 油价查询 | 国家发改委公告 | 每次调价 |
| 天气预报 | Open-Meteo 免费 API | 实时 |
| 潮汐预报 | 国家海洋局公式 | 每日 |
| LPR 利率 | 央行公告（内联） | 每月 |
| 实时汇率 | 欧洲央行免费 API | 实时 |
| 地铁时刻 | 杭州地铁官网（内联） | 静态 |

#### 3.2.3 便民工具
- 万年历：农历/节气/黄历
- 身份证校验：本地格式校验（不上传）
- 车牌归属：浙A/浙M 区域查询

### 3.3 电话页（Phone）

#### 3.3.1 常用电话簿
- 数据：21 个高频电话（含 12345/120/110/119/122 等急救+政务+民生）
- 分组：急救/政务/交通/水电燃气/通讯/医院

### 3.4 我的页（Me）

#### 3.4.1 用户卡片
- 头像：🏔️（杭州地标emoji）
- 昵称：iHangzhou 用户

#### 3.4.2 官方渠道

## 四、交互设计

### 4.1 全局交互
- **页面切换**：底部 Tab 切换，单页 SPA，无刷新
- **主题模式**：深色/浅色，本地存储 `theme` 字段，首次访问跟随系统
- **搜索**：实时模糊匹配服务名，回车跳转首个结果
- **模态框**：遮罩 + 弹层，支持 ESC/遮罩点击/关闭按钮三种关闭方式
- **Toast**：操作反馈（复制成功/分享提示），2.5s 自动消失

### 4.2 手势支持
- 顶部下拉：刷新页面
- 横向滑动：分类 Tab、资讯 Banner
- 长按电话号码：弹出拨号确认

### 4.3 加载与状态
- 首次加载：< 1s（静态资源 < 100KB）
- 离线访问：PWA 缓存核心页（首页/工具/电话）
- 错误态：网络请求失败显示"请检查网络后重试"

## 六、技术架构

### 6.1 技术栈
| 层 | 技术 |
|---|---|
| 模板 | 原生 HTML5 |
| 样式 | 原生 CSS3 + CSS Variables（暗色模式） |
| 交互 | 原生 JavaScript（IIFE，无框架） |


## 八、数据治理

### 8.1 数据原则
- **官方优先**：所有外链必须指向 .gov.cn / 官方品牌域
- **零存储**：不收集用户输入，不上传任何数据
- **本地计算**：所有计算器在浏览器本地完成
- **版本可控**：数据变更通过 Git 提交记录

### 8.2 数据维护
- 新增服务：编辑 `js/app.js` DATA 对应分类
- 新增工具：DATA 中加 `action` 字段 + app.js 实现 `handleAction`
- 热门词：编辑 `DATA.hotKeywords`
- 资讯 Banner：编辑 `index.html` 的 `.news-banner` 区块
